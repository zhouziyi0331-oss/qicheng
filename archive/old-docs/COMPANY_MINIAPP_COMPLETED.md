## 🏢 企业端小程序功能详情

### 页面结构

#### 1. 首页 (pages/index)
- **数据概览卡片**
  - 总任务数
  - 进行中任务
  - 已完成任务
  - 总支出金额
- **快速操作按钮**
  - 发布任务
  - 查看任务
  - 付款管理
- **最近任务列表**
  - 任务标题和状态
  - 执行学生信息
  - 进度条显示

#### 2. 任务管理 (pages/tasks)
- **标签页切换**
  - 全部任务
  - 进行中
  - 待处理
  - 已完成
- **任务卡片信息**
  - 任务标题和状态标签
  - 执行学生、预算、截止日期
  - 进度条
  - 操作按钮（确认完成、查看进度、查看匹配学生）

#### 3. 发布任务 (pages/publish)
- **表单字段**
  - 任务标题 (必填)
  - 任务描述 (必填，500字限制)
  - 任务类别 (选择器：软件开发、UI设计、文案撰写等)
  - 任务预算 (必填)
  - 截止日期 (日期选择器)
  - 技能要求 (200字限制)
- **发布提示**
  - AI自动匹配5位合适学生
  - 学生接受后企业从中选择1位
- **提交按钮**
  - 表单验证
  - 确认弹窗

#### 4. 付款管理 (pages/payments)
- **标签页**
  - 待处理（待付款、待确认）
  - 已完成
- **付款卡片**
  - 任务标题和状态
  - 执行学生
  - 金额（黄色高亮）
  - 截止日期/付款日期
  - 操作按钮（立即付款、查看详情、查看交付物）
- **底部统计**
  - 总支出
  - 待付款金额

#### 5. 企业中心 (pages/profile)
- **企业信息卡片**
  - 企业头像（首字母）
  - 企业名称
  - 行业和规模
- **统计数据**
  - 发布任务数
  - 进行中任务
  - 已完成任务
- **功能菜单**
  - 我的任务
  - 付款记录
  - 收藏的学生
  - 数据统计
  - 账号设置
  - 帮助中心
- **企业详细信息**
  - 联系人
  - 联系电话
  - 邮箱
- **退出登录按钮**

## 🎨 设计特点

### 深色主题
- 背景渐变: `linear-gradient(135deg, #1a1a2e 0%, #16213e 100%)`
- 卡片背景: `rgba(255, 255, 255, 0.08)` + 毛玻璃效果
- 边框: `rgba(255, 255, 255, 0.1)`

### 紫色渐变强调
- 主要按钮: `linear-gradient(135deg, #6366f1 0%, #8b5cf6 100%)`
- 统计卡片: 紫色渐变背景
- 进度条: 紫色渐变填充

### 状态标签颜色
- 进行中: 绿色 (#22c55e)
- 待确认: 黄色 (#fbbf24)
- 已完成: 蓝色 (#3b82f6)
- 待接单: 灰色 (#9ca3af)
- 待付款: 红色 (#ef4444)

## 🚀 启动方式

### 方式一：使用启动脚本（推荐）

```bash
# 启动学生端和企业端小程序
./start-miniapps.sh

# 停止所有小程序服务
./stop-miniapps.sh
```

### 方式二：手动启动

```bash
# 学生端小程序
cd /Users/alwan/code/qicheng/miniapp
npm run dev:weapp

# 企业端小程序（新开终端）
cd /Users/alwan/code/qicheng/company-miniapp
npm run dev:weapp
```

### 方式三：生产构建

```bash
# 学生端
cd miniapp && npm run build:weapp

# 企业端
cd company-miniapp && npm run build:weapp
```
