### P1: 核心功能开发（66%完成）

#### 5. 生命问题记录器（100%完成）
**数据库**：
```sql
CREATE TABLE life_questions (
  id UUID PRIMARY KEY,
  student_id UUID,
  question TEXT NOT NULL,
  reflections JSONB DEFAULT '[]'
);
```

**后端API**：
- `POST /api/life-question/save` - 保存/更新生命问题
- `GET /api/life-question/:userId` - 获取生命问题
- `POST /api/life-question/reflection` - 添加反思记录

**前端页面**：
- 页面路径：`pages/life-question/index`
- 输入框：你当下人生的生命问题是什么？
- 示例：我想知道自己真正喜欢什么
- AI导师使用说明：会在项目中探索这个问题
- 首页入口：完成OPC测试后显示

#### 6. 热情火花捕捉器（100%完成）
**数据库**：
```sql
CREATE TABLE passion_sparks (
  id UUID PRIMARY KEY,
  student_id UUID,
  task_id UUID,
  spark_text TEXT NOT NULL,
  context TEXT,
  want_explore BOOLEAN DEFAULT false
);
```

**后端API**：
- `POST /api/passion-spark/capture` - 捕捉热情火花
- `GET /api/passion-spark/:studentId` - 获取火花列表
- `POST /api/passion-spark/mark-explore` - 标记想要探索
- `GET /api/passion-spark/:studentId/want-explore` - 获取想探索的火花

**前端API服务**：
- `passionSparkAPI.capture()` - 捕捉火花
- `passionSparkAPI.getList()` - 获取列表
- `passionSparkAPI.markExplore()` - 标记探索
