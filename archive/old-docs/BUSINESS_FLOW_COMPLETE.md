# 启程平台 - 完整业务流程

## 📋 核心业务流程

### 1️⃣ 企业发布任务
1. 企业填写任务信息（标题、描述、类别、技能要求、截止日期）
2. **AI分析任务复杂度，给出价格区间**（例如：¥800-¥1500）
3. 企业在AI建议的区间内定价（例如：¥1200）
4. **企业支付30%定金到平台**（例如：¥360）
5. 任务状态：待匹配

### 2️⃣ AI智能匹配
1. **AI分析任务需求，推送10个最匹配的学生给企业**
2. 企业查看10个学生的：
   - 能力画像（六维雷达图）
   - 历史完成任务
   - 评分和评价
   - 匹配度百分比
3. **企业从10个中选择5个学生**
4. 系统向这5个学生发送任务邀请

### 3️⃣ 学生接单
1. 5个学生收到任务邀请通知
2. 学生看到的价格 = **企业报价 × 85%**（平台抽成15%）
   - 企业报价：¥1200
   - 学生看到：¥1020
   - 平台抽成：¥180
3. 学生可以选择：
   - ✅ 接受任务
   - ❌ 拒绝任务
4. **第一个接受的学生获得任务**，其他4个学生的邀请自动取消

### 4️⃣ 任务执行中
1. 学生开始执行任务
2. **企业可以实时查看**：
   - 哪个学生接单了
   - 任务进度（学生自己更新）
   - 学生提交的阶段性成果
3. **企业可以补充需求**：
   - 系统会提醒：补充需求会延长交付时间
   - 学生收到补充需求通知
   - 截止日期自动延长（根据需求复杂度）

### 5️⃣ 任务完成与验收
1. 学生完成任务，提交最终交付物
2. **AI自动审核**：
   - 检查交付物完整性
   - 验证功能是否符合需求
   - 生成审核报告
3. AI审核通过后，**发送给企业验收**：
   - 企业收到邮件通知
   - 企业在平台查看交付物（截图、视频、代码链接等）
   - 企业可以在线测试功能
4. **企业支付剩余70%尾款到平台**（例如：¥840）

### 6️⃣ 最终确认与付款
1. 企业调试验收，有两种情况：
   - ✅ **确认无问题**：点击确认，平台立即付款给学生
   - ⏰ **7天内未操作**：系统自动确认，平台自动付款给学生
2. 平台付款给学生：¥1020（85%）
3. 平台收取服务费：¥180（15%）
4. 任务状态：已完成

### 7️⃣ 长期合作激励
**连续合作2次同一学生 → 自动交换微信**
1. 系统检测到企业和学生完成第2次合作
2. **自动弹窗提醒**：
   - "您已与该学生合作2次，系统将为您交换微信联系方式"
   - "后续可直接联系，平台不再参与交易"
3. 双方可以看到对方微信号
4. 后续可以私下合作（平台不抽成）

## 🔄 任务状态流转

```
待匹配 → AI匹配中 → 待学生接单 → 进行中 → 待AI审核 → 
待企业验收 → 待支付尾款 → 待最终确认 → 已完成
```

### 详细状态说明
1. **待匹配**：企业已支付定金，等待AI分析
2. **AI匹配中**：AI正在分析并推送10个学生
3. **待学生接单**：企业已选5个学生，等待学生接单
4. **进行中**：学生已接单，正在执行任务
5. **待AI审核**：学生已提交，AI正在审核
6. **待企业验收**：AI审核通过，等待企业查看
7. **待支付尾款**：企业验收通过，等待支付尾款
8. **待最终确认**：尾款已支付，等待企业最终确认（7天倒计时）
9. **已完成**：企业确认或7天自动确认，平台已付款给学生

## 📧 通知机制

### 企业收到的通知
1. AI匹配完成，推送10个学生
2. 学生接单成功
3. 学生更新任务进度
4. 学生提交交付物
5. AI审核通过，请验收
6. 7天倒计时提醒（第5天、第6天）
7. 自动确认并付款通知
8. 连续合作2次，交换微信提醒

### 学生收到的通知
1. 收到任务邀请（5选1）
2. 企业补充需求
3. 截止日期延长通知
4. AI审核结果（通过/不通过）
5. 企业验收通过
6. 平台付款到账通知
7. 连续合作2次，交换微信提醒

## 🛡️ 风险控制

### 定金机制
- 企业必须先支付30%定金才能发布任务
- 防止企业恶意发布任务

### AI审核
- 自动检查交付物质量
- 减少人工审核成本
- 提高验收效率

### 7天自动确认
- 防止企业恶意拖延付款
- 保护学生权益
- 7天内企业可以充分测试

### 平台托管
- 所有款项先到平台
- 确认后才付给学生
- 保障双方权益
