# 基于"使命是河"理念的产品功能升级方案

使命是一条河，创造本身就是和河的跳动。不是证明自己多有用，而是对自己认真。

## 一、需要修改的现有功能

### 1. OPC测试结果页 - 增加"你的河道"板块

**当前问题**：只显示人格标签和维度解读，缺少"使命感"的引导

**修改方案**：
```
【你的河道】板块
- 标题："这是你的河，不是别人的"
- 内容：
  * "你的热情火花在哪里？" → 基于测试结果推测
  * "你的生命资产是什么？" → 列出3-5个独特优势
  * "你想探索什么模式？" → 开放式问题，让学生填写
  
【不是技能清单，是可能性地图】
- 不显示"你擅长XX技能"
- 改为"你可能在XX方向找到自己的河"
- 强调：这不是考试，是一面镜子
```

```
旧：冒险项目（高于你当前等级2级）
新：探索项目 - "这条河你没走过，要不要试试？"

【项目描述增加】
- "这个项目可能帮你发现什么？"（而非"你能学到什么技能"）
- "企业想找的不是工具人，是有自己想法的合伙人"
```

## 二、需要新增的功能

### 功能1：生命问题记录器

**位置**：首页 + 个人中心

**功能描述**：
```
【首次登录时】
弹窗："你当下人生的生命问题是什么？"
- 不是职业规划问题
- 不是技能学习问题
- 是你真正好奇的、困惑的、想探索的

【示例】
- "我想知道自己真正喜欢什么"
- "我想找到自己的节奏，不是别人的节奏"
- "我想看看AI能帮我做什么我自己做不到的事"

【AI导师的作用】
- 在项目执行中，会问："这个项目和你的生命问题有关系吗？"
- 在卡点时，会问："这个卡点是不是和你的生命问题有关？"
- 在完成时，会问："这个项目让你对自己的问题有新的看法吗？"
```

**数据库设计**：
```sql
CREATE TABLE life_questions (
  id UUID PRIMARY KEY,
  student_id UUID REFERENCES users(id),
  question TEXT NOT NULL,
  created_at TIMESTAMP,
  updated_at TIMESTAMP,
  reflections JSONB -- 记录在不同项目中的反思
);
```

---

### 功能2：热情火花捕捉器

**位置**：项目执行页面 + AI导师对话

**功能描述**：
```
【在项目执行中】
AI导师会问：
- "刚才做这个的时候，你有没有感觉到兴奋？"
- "你注意到自己在XX这里停留了很久，是因为有意思吗？"
- "你刚才说的XX，听起来你很有热情，要不要记下来？"

【记录格式】
不是"我学会了XX技能"
而是"我发现自己在XX这件事上有穿越感"

【热情火花库】
- 个人中心显示所有捕捉到的火花
- 不是技能清单，是"你可能喜欢的事"
- 可以标记："这个火花我想继续探索"
```

**数据库设计**：
```sql
CREATE TABLE passion_sparks (
  id UUID PRIMARY KEY,
  student_id UUID REFERENCES users(id),
  task_id UUID REFERENCES tasks(id),
  spark_text TEXT NOT NULL, -- "我发现自己在XX上有穿越感"
  context TEXT, -- 当时在做什么
  captured_at TIMESTAMP,
  want_explore BOOLEAN DEFAULT false -- 是否想继续探索
);
```

### 功能3：合伙人关系系统

**位置**：企业-学生互动页面

**功能描述**：
```
【第一次合作】
企业：发布项目
学生：接单
关系：雇佣关系

【第二次合作】
企业：邀请学生
学生：可以提出自己的想法
关系：开始建立信任

【第三次合作后】
触发"合伙人邀请"
企业可以发起："我们想和你建立长期合作，你愿意成为我们的合伙人吗？"

【合伙人权益】
- 可以参与项目设计（不只是执行）
- 可以提出自己的想法
- 收益分成比例提高
- 企业会投资你的成长（提供学习资源）
```

**数据库设计**：
```sql
CREATE TABLE partnerships (
  id UUID PRIMARY KEY,
  company_id UUID REFERENCES users(id),
  student_id UUID REFERENCES users(id),
  relationship_level VARCHAR(20), -- 'hired', 'trusted', 'partner'
  collaboration_count INTEGER DEFAULT 0,
  created_at TIMESTAMP,
  partnership_terms JSONB -- 合伙条款
);
```

### 功能4：探索模式加速器

**位置**：项目详情页 + 项目执行页

**功能描述**：
```
【项目标签新增】
不只是"技能标签"（Figma、Python）
增加"探索标签"：
- 🔍 探索新工具
- 🎨 探索新风格
- 🤝 探索新协作方式
- 💡 探索新思路

【项目描述增加】
"这个项目可能帮你探索什么模式？"
- 示例："这个项目可能帮你探索：如何用AI快速验证想法"
- 示例："这个项目可能帮你探索：如何在限制中找到创意"

【完成后反思】
不只是"评价任务"
增加"探索反思"：
- "这个项目让你发现了什么新模式？"
- "你在这个项目中找到了什么更好的做法？"
- "你会把这个模式用到生活的其他地方吗？"
```

### 功能5：OPC孵化计划

**位置**：Lv.4（自流者）解锁

**功能描述**：
```
【触发条件】
- 完成20个项目
- 等级达到Lv.4（自流者）
- 找到了自己的热情方向

【孵化内容】
平台提供：
1. OPC成长报告（¥299）免费
2. 独立接单资格（可以脱离平台）
3. 联合体组建支持（可以邀请其他学生组队）
4. 创业资源对接（投资人、导师、场地）

【硬承诺】
学生承诺：
- 每月回来更新一次成长报告
- 分享自己的探索经验到故事墙
- 帮助新人（成为导师）

平台承诺：
- 永久保留成长数据
- 优先推荐高质量项目
- 提供持续的成长资源
```

**数据库设计**：
```sql
CREATE TABLE opc_incubation (
  id UUID PRIMARY KEY,
  student_id UUID REFERENCES users(id),
  status VARCHAR(20), -- 'applying', 'incubating', 'graduated'
  passion_direction TEXT, -- 热情方向
  team_members UUID[], -- 联合体成员
  monthly_updates JSONB[], -- 每月更新记录
  created_at TIMESTAMP
);
```

### 功能6：穿越感时刻记录

**位置**：AI导师对话 + 项目执行页

**功能描述**：
```
【什么是穿越感】
- 做某件事时，感觉时间过得特别快
- 做某件事时，感觉自己特别投入
- 做某件事时，感觉"这就是我想做的"

【AI导师捕捉】
在项目执行中，AI会问：
- "你刚才做这个的时候，有没有感觉时间过得特别快？"
- "你注意到自己刚才特别投入吗？"

【记录展示】
个人中心显示：
- "你的穿越感时刻"
- 不是成就列表，是"你真正享受的时刻"
- 可以看到模式："你在XX类型的事情上最有穿越感"
```

### 1. 数据库新增表

- passion_sparks（热情火花）
- partnerships（合伙人关系）
- opc_incubation（OPC孵化）
- flow_moments（穿越感时刻）

### 2. AI导师Prompt升级
```
旧Prompt：你是一个AI导师，帮助学生完成任务
新Prompt：你是一个先走过这条河的人，不是来教技能的，是来帮学生看见自己的。

核心原则：
- 不问"你学会了什么技能"
- 问"你发现了什么关于自己的事"
- 不说"你做错了"
- 说"你注意到这里可以不一样吗？"
- 捕捉热情火花："你刚才说XX的时候，听起来很有热情"
- 连接生命问题："这个和你的生命问题有关系吗？"
```
