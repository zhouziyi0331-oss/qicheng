### 3.6 查数据库行数关系

**操作**:
让开发者查询以下数据：

```sql
-- 订单数 vs 导师消息数
SELECT 
  (SELECT COUNT(*) FROM orders WHERE status = 'completed') as completed_orders,
  (SELECT COUNT(*) FROM mentor_sessions) as mentor_messages;

-- 每个完成的订单至少应该有5条导师消息
```

**期望**:

## 📝 附录：常见假壳子特征

### 前端假壳子的典型特征

1. **写死的假数据**
   - 代码里有 `const mockData = [...]`
   - 没有网络请求，数据直接从本地返回

2. **假的loading动画**
   - `setTimeout(() => { setLoading(false) }, 1000)` 
   - 没有真实的API调用

3. **模板化的文案**
   - 所有用户看到的文案都一样
   - 没有动态插值，如 `${studentName}`

4. **假的个性化**
   - 前端随机生成数据，如 `Math.random() * 100`
   - 刷新页面后数据变化（说明不是从后端获取）

### 如何快速识别假壳子

1. **打开浏览器开发者工具 → Network标签**
   - 操作时没有网络请求 = 假壳子
   - 请求返回的是静态JSON = 假壳子

2. **对比两个不同用户的体验**
   - 体验高度相似 = 假壳子
   - 文案一模一样 = 假壳子

3. **查看源代码**
   - 搜索 `mockData`、`fakeData`、`testData`
   - 搜索 `setTimeout`（假loading）
   - 搜索硬编码的文案
