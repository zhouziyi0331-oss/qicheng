```
┌─────────────────────────────────────────────────────┐
│                    客户端请求                        │
└───────────────────┬─────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────────────┐
│                 Express API                          │
│  - 立即返回响应 (<200ms)                             │
│  - 推送任务到队列                                    │
└───────────────────┬─────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────────────┐
│               Bull Queue (Redis)                     │
│  - matchingQueue (并发5)                             │
│  - notificationQueue                                 │
│  - aiQueue (限流10/min)                              │
└───────────────────┬─────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────────────┐
│                Worker进程                            │
│  - 异步处理任务                                      │
│  - 实时推送进度                                      │
│  - 完成后通知前端                                    │
└───────────────────┬─────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────────────┐
│              WebSocket推送                           │
│  - 实时通知客户端                                    │
└─────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────┐
│                   API请求                            │

                    │
                    ▼
           ┌────────────────┐
           │ Redis缓存检查   │
           └────────┬────────┘
                    │
        ┌───────────┴───────────┐
        │                       │
    命中缓存                 未命中
        │                       │

                           │
                           ▼
                     写入缓存+返回
                     (<100ms)
```

## 🚀 部署步骤

### 1. 安装依赖

```bash
cd backend
npm install bull @types/bull ioredis redis
```

### 2. 启动Redis

```bash
# Docker方式
docker run -d --name qicheng-redis -p 6379:6379 redis:7

# 或使用docker-compose
cat >> docker-compose.yml << 'YAML'
services:
  redis:
    image: redis:7
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data
volumes:
  redis-data:
YAML

docker-compose up -d redis
```

### 3. 执行数据库迁移

```bash
psql -d qicheng_db -f migrations/118_cross_platform_integration.sql
psql -d qicheng_db -f migrations/119_performance_optimization.sql
```

### 4. 启动应用

```bash
# 终端1: 启动主应用
npm start

# 终端2: 启动Worker
npm run worker

# 或使用PM2
pm2 start ecosystem.config.js
```

### 5. 验证部署

```bash
# 检查队列健康
curl http://localhost:3000/api/v1/monitoring/queues/health

# 检查物化视图
psql -d qicheng_db -c "SELECT * FROM v_materialized_view_stats;"

# 检查Redis连接
redis-cli ping
```
