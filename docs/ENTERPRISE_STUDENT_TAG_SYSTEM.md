### 2. 任务特征标签 (800个)

#### 2.1 任务类型 (100个)
- **按交付物**:
  - 文档类: Word文档、Excel表格、PPT演示、PDF报告、思维导图、流程图、原型图...
  - 内容类: 短视频、图文内容、音频、直播脚本、文案、广告语、标题...
  - 设计类: 海报、Banner、详情页、主图、Logo、UI设计、配色方案...
  - 技术类: Agent搭建、API集成、自动化脚本、数据爬取、网页开发、小程序...
  - 数据类: 数据分析报告、可视化图表、数据清洗、数据标注...
  - 方案类: 营销方案、运营方案、商业计划、培训方案、流程优化方案...

- **按执行方式**:
  - 一次性任务、重复性任务、长期维护、紧急任务、灵活时间任务...

#### 2.2 任务复杂度 (200个)
- **简单任务** (100个): 单一步骤、明确需求、有模板、可复制...
  - 示例: 使用ChatGPT生成10条商品描述、整理Excel数据、设计一张海报、搭建简单问答Agent...
  
- **中等任务** (50个): 多步骤流程、需要理解、需要优化...
  - 示例: 完整短视频制作(策划+拍摄+剪辑)、店铺诊断+优化方案、多平台内容分发...
  
- **复杂任务** (50个): 系统性工作、需要深度理解、需要创新...
  - 示例: 完整营销campaign、Agent工作流搭建、数据分析+洞察+建议、运营体系搭建...

#### 2.3 需求明确度 (100个)
- **清晰需求** (30个): 需求明确、有参考、有标准、有模板...
- **模糊需求** (40个): 需要理解、需要沟通、需要确认、需要优化...
- **开放需求** (30个): 需要创意、需要探索、需要提建议、需要迭代...

#### 2.4 学习曲线 (200个)
- **零基础可做** (80个): 不需要任何技能、有教程、有模板、照着做就行...
- **需要学习新工具** (60个): 需要学会某个工具(如Midjourney)、有教程可学、1-3天能上手...
- **需要一定理解** (40个): 需要理解业务逻辑、需要学习行业知识、需要思考优化...
- **需要深度掌握** (20个): 需要深入理解、需要经验积累、不适合小白...

#### 2.5 时间要求 (100个)
- 1小时内、半天、1天、2-3天、1周、2周、1个月、长期...
- 灵活时间、固定时间、紧急任务、工作日、周末...

#### 2.6 沟通频率 (100个)
- 自主完成无需沟通、开始前确认需求、完成后交付、过程中定期同步、实时沟通、高频反馈...

## 四、标签的使用流程

### 1. 企业发布任务时
```
1. 选择业务领域 (如: 电商 → 选品分析)
2. 选择需要的工具 (如: ChatGPT, Excel)
3. 标注任务特征 (如: 简单任务、清晰需求、1天完成、零基础可做)
4. 添加业务关键词 (如: 转化率、竞品分析、数据驱动)
5. AI自动从任务描述中提取补充标签
```

### 2. 学生完成任务后
```
1. 自动记录: 使用了哪些工具 → 增加工具掌握标签
2. 自动记录: 完成了什么类型的案例 → 增加案例标签
3. 企业评价: 质量、速度、沟通 → 推断能力标签
4. AI分析: 从聊天记录、交付物分析执行过程 → 更新能力标签
5. 更新OPC 6维分数
6. 记录成长轨迹
```

### 3. 匹配时
```
基于:
- 学生的工具掌握标签 ↔ 任务需要的工具
- 学生的案例经验 ↔ 任务的业务领域
- 学生的能力标签 ↔ 任务的复杂度/需求明确度
- 学生的OPC 6维 ↔ 任务的执行方式要求
- 学生的成长潜力 ↔ 任务的学习曲线

算法:
- 完全匹配: 学生有这个工具和案例经验 (高分)
- 可学习匹配: 学生有相关经验+学习能力强+任务有教程 (中高分)
- 小白匹配: 任务标记"零基础可做"+有详细教程 (中分)
- 不匹配: 任务复杂+学生无相关经验+无教程 (低分)
```
