# 图标设计更新说明

## 设计风格
所有图标采用"纯色圆形底色 + 黑色线条图标"的设计风格

### 设计规范
- **圆形底色**：马卡龙色系
  - 嫩草绿：#D4F291
  - 樱花粉：#F9C6D9
  - 天空蓝：#A8D8EA
  - 奶油黄：#FFE082
  - 活力橙：#FFB84D

- **SVG图标**：
  - 颜色：黑色 (#2D3436)
  - 线条粗细：2px
  - 端点样式：圆头 (round)
  - 填充：无填充 (none)
