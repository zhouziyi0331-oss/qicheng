## 🔌 API对接

所有API已在 `src/services/api.ts` 中定义，复用Web端的API：

```typescript
// 基础URL
const BASE_URL = 'http://localhost:3001/api/v1'

// API模块
- authAPI      // 用户认证（登录、注册、验证码）
- testAPI      // OPC测评
- taskAPI      // 任务系统
- mentorAPI    // AI导师 🐱
- abilityAPI   // 能力系统
- storyAPI     // 故事墙
- reportAPI    // OPC报告
- withdrawAPI  // 提现
```

### 修改API地址
编辑 `src/services/api.ts` 第3行：
```typescript
const BASE_URL = 'https://your-api-domain.com/api/v1'
```

## 🐛 常见问题

### Q: 提示"模拟器启动失败"
A: 检查 `dist/app.json` 文件是否存在，确保编译成功

### Q: 页面显示空白
A: 检查微信开发者工具控制台的错误信息，可能是API请求失败

### Q: TabBar 图标不显示
A: 当前使用的是占位图标，可以替换 `src/assets/icons/` 目录下的图标文件

### Q: API请求失败
A: 
1. 检查后端服务是否启动
2. 修改 `src/services/api.ts` 中的 `BASE_URL`
3. 在微信开发者工具中勾选「不校验合法域名」
