## 🐛 发现并修复的问题

### 问题1: 控制器userId访问错误
**描述**: 新控制器使用 `req.user.userId` 而非 `req.userId`  
**影响**: 所有新功能API返回500错误  
**修复**: 统一修改为 `req.userId` 并添加未授权检查  
**状态**: ✅ 已修复

### 问题2: auth中间件导出不一致
**描述**: 部分路由导入 `authenticateToken`，部分导入 `authMiddleware`  
**影响**: 编译错误  
**修复**: 添加别名导出，创建auth.ts重导出文件  
**状态**: ✅ 已修复
