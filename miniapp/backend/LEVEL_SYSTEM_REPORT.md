## 📊 系统概览

### 设计理念："使命是河"

从涉水到河成的成长旅程，每个等级代表着与"河流"的不同关系：

| 等级 | 名称 | 英文 | 图标 | 理念 |
|------|------|------|------|------|
| Lv.1 | 涉水者 | Wader | 🦶 | 刚刚踏入河流，小心翼翼地试探 |
| Lv.2 | 试流者 | Flow Seeker | 🌊 | 开始感受水流的力量，学会顺流 |
| Lv.3 | 行舟者 | Navigator | ⛵ | 能够驾驭小舟，在河流中自如移动 |
| Lv.4 | 知向者 | Direction Finder | 🧭 | 不仅懂水流，还能判断方向 |
| Lv.5 | 自流者 | Self Flow | 💫 | 找到自己的节奏，不需要外界指引 |
| Lv.6 | 河成者 | River Maker | 🌈 | 成为河流本身，共创、传承 |

### 1. 等级配置系统 (level.config.ts)

#### 等级数据结构
```typescript
{
  level: number              // 等级编号
  name: string              // 中文名称
  title: string             // 英文名称
  description: string       // 等级描述

  color: string             // 主题色
```

- Lv.3 行舟者: 3000 → 6000 经验 (需累计6000)

- Lv.5 自流者: 10000 → 15000 经验 (需累计15000)
- Lv.6 河成者: 15000+ 经验 (最高等级)

### 5. 服务层 (level.service.ts)

#### 核心方法

**getUserLevel(userId)**
- 获取用户完整等级信息
- 包含当前等级、下一等级、升级进度

**addExp(userId, exp, reason, metadata)**
- 增加经验值
- 自动检测升级
- 记录经验值历史
- 触发升级事件

**addExpForProjectCompletion(userId, projectId, difficulty, rating)**
- 项目完成时自动增加经验值
- 计算难度奖励、评价奖励、首次奖励

**addExpForOPCCompletion(userId)**
- OPC测评完成时增加经验值

**checkMilestones(userId)**
- 检查并解锁里程碑成就
- 自动发放里程碑奖励

**getLevelLeaderboard(limit)**
- 获取等级榜单
- 按等级和经验值排序

## 🔄 自动集成

### 项目完成时
在 `realProject.service.ts` 中，项目完成时自动：
1. 增加经验值（基于难度）
2. 检查里程碑
3. 触发升级事件

```typescript
// 项目完成后
await levelService.addExpForProjectCompletion(
  userId,
  projectId,
  difficulty,
  rating
)
await levelService.checkMilestones(userId)
```

### OPC测评完成时
在 `opc.service.ts` 中，测评完成时自动：
1. 增加50经验值
2. 记录首次完成

```typescript
// OPC测评完成后
await levelService.addExpForOPCCompletion(userId)
```

## 🎨 等级设计亮点

### 1. 富有诗意的命名
不是传统的"青铜、白银、黄金"，而是"涉水者→河成者"，体现成长旅程

### 2. 清晰的进阶逻辑
- Lv.1-2: 试探和适应（easy → medium）
- Lv.3-4: 掌握和引领（hard → expert）
- Lv.5-6: 创造和传承（导师、合伙人）

### 3. 多维度经验获取
不只是完成项目，还包括：
- 成长行为（热情火花、穿越感）
- 社区贡献（帮助他人、分享经验）

### 4. 里程碑激励
每个等级都有明确的里程碑，给予成就感和方向感

### 5. 渐进式解锁
随着等级提升，逐步解锁新功能和权益，保持新鲜感

## 💡 设计思考

### 为什么是6个等级？
- 3个等级太少，缺少进阶感
- 10个等级太多，容易疲劳
- 6个等级恰到好处：
  - 1-2: 新手期（快速体验）
  - 3-4: 成长期（深入探索）
  - 5-6: 大师期（长期追求）

### 为什么经验值设计这样分布？
- Lv.1→2 (1000→3000): 2倍差距，引导完成多个项目
- Lv.2→3 (3000→6000): 2倍差距，需要更多实践
- Lv.3→4 (6000→10000): 1.67倍，进入平台期
- Lv.4→5 (10000→15000): 1.5倍，追求卓越
- Lv.5→6 (15000+): 最高境界，持续成长

### "使命是河"的隐喻
- 河流不断流动，象征持续成长
- 每个人在河中找到自己的节奏
- 最终不是征服河流，而是成为河流本身
- 强调共生、传承、生生不息
