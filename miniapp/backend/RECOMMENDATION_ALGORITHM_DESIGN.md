## 📊 多维度推荐系统设计

### 1. 推荐分数计算公式

```typescript
最终推荐分数 = 
  技能匹配度 * W1 +           // 40% - 向量相似度
  难度适配度 * W2 +           // 25% - 能力与难度匹配
  兴趣匹配度 * W3 +           // 15% - 个人兴趣偏好
  成功概率 * W4 +             // 10% - 历史成功率
  预算匹配度 * W5 +           // 5% - 预算期望
  时间匹配度 * W6             // 5% - 时间投入
```

**默认权重**：
- W1 = 0.40 (技能最重要)
- W2 = 0.25 (难度适配很重要)
- W3 = 0.15 (兴趣影响接单率)
- W4 = 0.10 (历史表现)
- W5 = 0.05 (预算期望)
- W6 = 0.05 (时间投入)

**个性化权重调整**：
```typescript
// 新手学生（Level 1-2）
W1 = 0.35, W2 = 0.35 (更看重难度)

// 中级学生（Level 3-5）
W1 = 0.40, W2 = 0.25 (平衡)

// 高级学生（Level 6+）
W1 = 0.45, W3 = 0.20 (更看重兴趣)
```

### 2. 各维度计算细节

#### 维度1：技能匹配度（40%）

**计算方法**：
```typescript
技能匹配度 = 基础向量相似度 * 标签覆盖加成 * 专业深度加成

基础向量相似度 = 1 - cosineDistance(studentVector, projectVector)

标签覆盖加成 = 1 + (匹配标签数 / 项目所需标签数) * 0.2
// 例：项目需要5个标签，学生匹配4个 → 加成 1.16

专业深度加成 = 1 + (核心标签权重和 / 总标签数) * 0.15
// 学生在核心标签上的权重越高，加成越多
```

**示例**：
```
学生：平面设计(0.9), UI设计(0.8), Figma(0.7)
项目：需要 平面设计, UI设计, 品牌设计

向量相似度: 0.92
标签覆盖: 2/3 = 66% → 加成 1.13
专业深度: (0.9+0.8)/2 = 0.85 → 加成 1.13

最终技能匹配度 = 0.92 * 1.13 * 1.13 = 1.18 (归一化到1.0)
```

---

#### 维度2：难度适配度（25%）

**基于能力曲线**：
```typescript
学生能力值 = Level * 10 + Experience / 100 + 项目完成加成

项目难度值:
  easy: 10-30
  medium: 30-50
  hard: 50-80
  expert: 80-100

难度匹配曲线（高斯分布）：
  完全匹配: 1.0 (能力 = 难度)
  略高挑战: 0.95 (能力 = 难度 + 10)
  适度挑战: 0.85 (能力 = 难度 + 20)
  过高挑战: 0.5 (能力 < 难度 - 20)
  过低无聊: 0.6 (能力 > 难度 + 30)
```

**计算公式**：
```typescript
diff = studentAbility - projectDifficulty

if (diff >= -10 && diff <= 20) {
  // 最佳区间：略低到适度挑战
  score = 1.0 - Math.abs(diff - 5) * 0.02
} else if (diff < -10) {
  // 太难
  score = Math.max(0.3, 0.8 + diff * 0.025)
} else {
  // 太简单
  score = Math.max(0.5, 1.0 - (diff - 20) * 0.015)
}
```

**示例**：
```
学生能力: 45 (Level 4, Experience 500)
项目难度: 50 (medium)

diff = -5 (略有挑战)
难度适配度 = 1.0 - |-5 - 5| * 0.02 = 0.8
```

#### 维度3：兴趣匹配度（15%）

**基于历史行为**：
```typescript
兴趣分数 = 
  类别偏好 * 0.4 +           // 设计类 vs 开发类
  领域偏好 * 0.3 +           // 电商 vs 教育 vs 金融
  工具偏好 * 0.2 +           // Figma vs Sketch
  风格偏好 * 0.1             // 创意型 vs 技术型

类别偏好计算:
  该类别完成项目数 / 总完成项目数
  
领域偏好计算:
  该领域停留时间 / 总时间
  
工具偏好计算:
  该工具使用次数 / 总次数
```

**冷启动处理**：
```typescript
// 新用户没有历史数据
if (totalProjects < 3) {
  // 使用OPC测评结果
  兴趣分数 = OPC标签匹配度 * 0.7 + 初始标签匹配度 * 0.3
} else {
  // 使用历史行为
  兴趣分数 = 历史行为计算
}
```

---

#### 维度4：成功概率（10%）

**预测学生完成项目的概率**：
```typescript
成功概率 = 
  历史完成率 * 0.4 +          // 接单完成比例
  技能稳定性 * 0.3 +          // 技能是否稳定
  难度适配 * 0.2 +            // 能力匹配
  时间履约 * 0.1              // 按时完成率

历史完成率 = 完成项目数 / 接受项目数

技能稳定性 = 1 - (技能方差 / 平均技能水平)
// 学生技能越集中，越稳定

难度适配 = 使用维度2的结果

时间履约 = 按时完成项目数 / 总完成项目数
```

**新用户成功概率**：
```typescript
if (totalProjects < 5) {
  // 基于Level和标签数预估
  成功概率 = 
    (Level / 10) * 0.5 +
    (标签数 / 20) * 0.3 +
    (OPC测评分数 / 100) * 0.2
}
```

---

#### 维度5：预算匹配度（5%）

**基于历史接单行为**：
```typescript
学生预算偏好范围:
  平均接单预算 ± 标准差

项目预算匹配:
  if (项目预算 在偏好范围内) {
    score = 1.0
  } else if (项目预算 > 上限) {
    // 高于期望，加分
    score = 1.0 + Math.min((项目预算 - 上限) / 上限 * 0.2, 0.2)
  } else {
    // 低于期望，减分
    score = Math.max(0.5, 项目预算 / 下限)
  }
```

**冷启动**：
```typescript
// 新用户没有偏好
预算匹配度 = 1.0 // 不影响推荐
```

---

#### 维度6：时间匹配度（5%）

**基于学生可用时间**：
```typescript
学生可用时间 = 
  每周活跃小时数
  
项目预估时间 = 
  difficulty * 时间系数 * (1 - 技能匹配度)
  
时间匹配度 = 
  if (项目时间 <= 学生可用时间) {
    1.0
  } else {
    学生可用时间 / 项目时间
  }
```

## 🔄 学习和优化机制

### 1. 负样本学习

**记录用户行为**：
```typescript
interface UserFeedback {
  // 推荐了但没接
  rejected: {
    projectId: string
    reason?: 'difficulty' | 'budget' | 'interest' | 'time'
    timestamp: Date
  }[]
  
  // 接了但没完成
  abandoned: {
    projectId: string
    reason?: string
    completionRate: number
  }[]
  
  // 完成了但评价低
  lowRated: {
    projectId: string
    rating: number
    feedback: string
  }[]
}
```

**调整推荐策略**：
```typescript
// 如果用户经常拒绝某类项目
if (rejectedCategory频率 > 30%) {
  类别权重 -= 0.1
}

// 如果用户经常放弃高难度项目
if (abandoned项目难度 > 能力水平 + 20) {
  难度权重 += 0.05 // 更看重难度匹配
}

// 如果低评价项目都是某个领域
if (lowRated领域集中度 > 50%) {
  该领域权重 -= 0.15
}
```

### 2. 协同过滤

**利用相似学生的数据**：
```typescript
// 找到相似学生（向量相似 + 行为相似）
similarStudents = findSimilarStudents(currentStudent, top: 20)

// 他们喜欢的项目，当前学生可能也喜欢
collaborativeScore = 
  similarStudents
    .filter(s => s.completed(project))
    .map(s => s.rating(project) * similarity(s, currentStudent))
    .average()

// 混合到推荐分数
finalScore = contentBasedScore * 0.8 + collaborativeScore * 0.2
```

## 🎯 推荐流程

```
1. 获取学生画像
   ├─ 技能向量
   ├─ 能力水平
   ├─ 历史行为
   └─ 偏好设置

2. 候选项目筛选
   ├─ 基础向量检索（Top 100）
   ├─ 过滤已完成/已拒绝
   └─ 过滤明显不匹配

3. 多维度打分
   ├─ 技能匹配（40%）
   ├─ 难度适配（25%）
   ├─ 兴趣匹配（15%）
   ├─ 成功概率（10%）
   ├─ 预算匹配（5%）
   └─ 时间匹配（5%）

4. 排序和多样性
   ├─ 按综合分数排序
   ├─ 插入探索项目（10%）
   └─ 保证类别多样性

5. 个性化调整
   ├─ 根据实时状态
   ├─ 根据历史反馈
   └─ 动态权重

6. 返回Top N
```
