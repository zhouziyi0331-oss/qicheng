## 🚀 使用流程

### Step 1: 导入标签库

```bash
# 需要配置OpenAI API Key
# .env文件中添加：
OPENAI_API_KEY=你的真实密钥

# 导入2000+标签
npx ts-node src/scripts/importCompleteTags.ts
```

### Step 2: 学生画像初始化

```typescript
// 学生完成OPC测评后
POST /api/vector-match/student/profile/initialize

// 自动提取：
// - OPC人格 → 个人特质标签
// - 维度分数 → 个人优势标签
// - 生成学生向量 → 存入Qdrant
```

### Step 3: 项目画像创建

```typescript
// 企业发布项目时
POST /api/vector-match/project/profile

{
  "projectId": "...",
  "projectType": "real",
  "taskType": "Logo设计",
  "requirements": ["需要创意想法", "需要年轻化风格"],
  "difficulty": "中级项目",
  "industry": "美妆个护",
  "budget": "3000-5000元",
  "deliveryCycle": "1周内"
}

// 自动：
// - 匹配标签 → 生成项目向量 → 存入Qdrant
```

### Step 4: 智能推荐

```typescript
// 学生端：推荐项目
GET /api/vector-match/recommendations?limit=20

// 企业端：推荐学生
GET /api/vector-match/students?projectId=xxx&limit=20
```

## 📈 动态更新机制

### 1. 学生完成项目 → 自动更新

```typescript
// 项目完成后
onProjectCompleted(userId, projectId) {
  // 分析项目，提取新标签
  const newTags = [
    "做过品牌设计项目",
    "擅长Logo设计",
    "从0到1做过产品"
  ]
  
  // 更新学生标签画像
  addStudentTags(userId, newTags)
  
  // 重新生成向量
  updateStudentVector(userId)
  
  // 更新Qdrant
  qdrantVectorService.upsertStudentProfile(userId, newVector)
}
```

### 2. 企业发布项目 → 自动解析

```typescript
// 项目发布时
onProjectPublished(projectId, description) {
  // AI解析项目需求
  const analysis = await analyzeProjectWithAI(description)
  
  // 匹配到标签库
  const matchedTags = matchTags(analysis)
  
  // 生成项目向量
  const projectVector = generateVector(matchedTags)
  
  // 存入Qdrant
  qdrantVectorService.upsertProjectProfile(projectId, projectVector)
}
```
