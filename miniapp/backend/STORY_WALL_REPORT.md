故事墙是"使命是河"成长体系的情感展示空间，让学生的成长不只是数据和等级，而是鲜活的故事和真实的情感。通过记录和分享：
- 🌟 **成长故事** - 关键节点的突破和转变
- 🔥 **热情火花** - 发现热爱的瞬间
- ⚡ **穿越感时刻** - 心流状态的体验
- 🎯 **生命问题探索** - 深层次的自我认知

## 🎯 已实现功能

### 1. 数据模型 (3个)

#### Story (故事模型)
```typescript
{
  userId: ObjectId              // 用户ID
  type: string                  // 故事类型: growth_story | passion_spark | flow_moment | life_question
  title: string                 // 标题 (最多100字)
  content: string               // 内容 (最多2000字)
  relatedProjectId?: ObjectId   // 关联项目
  relatedOPCResultId?: ObjectId // 关联OPC测评
  tags: string[]                // 标签
  isPublic: boolean             // 是否公开
  likeCount: number             // 点赞数
  viewCount: number             // 浏览数
  metadata?: object             // 元数据(等级变化、成就、情感等)
  createdAt: Date               // 创建时间
  publishedAt?: Date            // 发布时间
}
```

#### PassionSpark (热情火花模型)
```typescript
{
  userId: ObjectId              // 用户ID
  content: string               // 火花内容
  trigger: string               // 触发场景
  relatedProjectId?: ObjectId   // 关联项目
  intensity: number             // 强度 (1-5)
  tags: string[]                // 标签
  isShared: boolean             // 是否分享到故事墙
  storyId?: ObjectId            // 关联的故事ID
  createdAt: Date               // 创建时间
}
```

#### StoryLike (点赞模型)
```typescript
{
  userId: ObjectId              // 点赞用户ID
  storyId: ObjectId             // 故事ID
  createdAt: Date               // 点赞时间
}
```

### 2. 服务层功能 (storyWall.service.ts)

#### 核心方法

**createStory(userId, data)**
- 创建故事（成长故事、热情火花、穿越感、生命问题）
- 自动增加经验值 (+50)
- 支持公开/私密设置

**getPublicStories(filters)**
- 获取公开故事列表
- 支持按类型筛选
- 支持按标签筛选
- 支持最新/热门排序
- 支持分页

**getUserStories(userId, includePrivate)**
- 获取用户的故事列表
- 可选查看私密故事

**getStoryDetail(storyId, viewerId)**
- 获取故事详情
- 自动增加浏览量
- 返回当前用户是否已点赞

**likeStory(userId, storyId)**
- 点赞/取消点赞
- 自动更新点赞数

**recordPassionSpark(userId, data)**
- 记录热情火花
- 自动增加经验值 (+20)
- 可选分享到故事墙（自动创建story）

**getUserPassionSparks(userId)**
- 获取用户的热情火花列表

**getStoryWallStats()**
- 获取故事墙统计数据
- 总故事数、总点赞数、总浏览数
- 故事类型分布

**getUserStoryStats(userId)**
- 获取用户的故事统计

## 💡 设计思考

### 为什么需要故事墙？

1. **情感连接**
   - 数字化成长容易冰冷，故事让成长有温度
   - 看到他人的故事，感受"我不是一个人在战斗"

2. **自我认知**
   - 写下来的过程就是反思的过程
   - 回看过去的故事，看到自己的成长轨迹

3. **社区氛围**
   - 优质内容激励他人
   - 形成正向的成长文化

4. **长期价值**
   - 不只是完成项目赚钱，更是积累人生故事
   - 这些故事将成为宝贵的人生资产

### "使命是河"在故事墙的体现

- **涉水者** → 分享第一个故事，记录初次踏入河流
- **试流者** → 开始感受热情火花，发现自己的节奏
- **行舟者** → 经历穿越感时刻，在心流中自如移动
- **知向者** → 探索生命问题，找到自己的方向
- **自流者** → 形成独特的成长故事风格
- **河成者** → 故事影响他人，共创成长河流
