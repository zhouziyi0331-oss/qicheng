## 🐛 常见问题

### Q1: 页面打不开？
**A:** 检查是否已在 `app.config.ts` 中注册页面。查看：
```typescript
pages: [
  // ...
  'pages/level-up-test/index',
  'pages/level-up-validation/index',
  'pages/level-up-done/index',
]
```

### Q2: 样式不对？
**A:** 确保scss文件已编译。查看 `dist` 目录是否有对应的wxss文件。

### Q3: API调用失败？
**A:** 当前使用模拟数据作为降级方案，不影响测试体验。

### Q4: 动画卡顿？
**A:** 在真机上测试，开发者工具性能较低可能影响动画流畅度。
