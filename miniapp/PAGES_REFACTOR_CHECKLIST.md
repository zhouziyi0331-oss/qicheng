## 🔧 改造模板

每个页面的改造checklist：

### 视觉升级
- [ ] 背景色：莫兰迪 → 果汁色（var(--theme-bg)）
- [ ] 卡片：8px圆角 → 16px圆角
- [ ] 卡片：无阴影 → var(--shadow-card)
- [ ] 按钮：方形 → 胶囊型（border-radius: var(--radius-round)）
- [ ] 按钮：静态 → 点击scale(0.95)
- [ ] 文字：系统灰 → 可可色（var(--text-primary)）

### 动画升级
- [ ] 页面加载：白屏 → 骨架屏shimmer
- [ ] 列表入场：瞬间 → 交错slideInUp
- [ ] 数字显示：直接 → 翻滚动画
- [ ] AI等待：转圈 → AIWaitingScreen组件
- [ ] 空状态：纯文字 → 插图+引导

### 交互升级
- [ ] 卡片hover：无 → translateY(-4px)
- [ ] 按钮点击：无 → scale(0.95) + 震动
- [ ] 成功提示：Toast → 动画组件
- [ ] 页面切换：无 → 滑动过渡
