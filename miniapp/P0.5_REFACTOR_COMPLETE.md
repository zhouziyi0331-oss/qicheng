## 🔧 技术细节

### CSS变量使用
```scss
// 主题色
var(--theme-primary)      // 蓝莓蓝 #4ECDC4
var(--theme-accent)       // 渐变辅助色
var(--theme-bg)          // 背景色
var(--theme-card)        // 卡片背景

// 果汁色
var(--strawberry-pink)   // 草莓粉 #FFF0F3
var(--blueberry-blue)    // 蓝莓蓝 #4ECDC4
var(--grapefruit-orange) // 葡萄柚橙 #FF6B6B
var(--mango-yellow)      // 芒果黄 #FFE66D
var(--watermelon-red)    // 西瓜红（强调）

// 阴影
var(--shadow-card)       // 卡片阴影
var(--shadow-soft)       // 柔和阴影
var(--shadow-hover)      // 悬停阴影

// 圆角
var(--radius-small)      // 小圆角 8rpx
var(--radius-medium)     // 中圆角 12rpx
var(--radius-large)      // 大圆角 16rpx
var(--radius-round)      // 全圆角 999rpx

// 缓动函数
var(--ease-standard)     // 标准缓动
var(--ease-decelerate)   // 减速缓动
var(--ease-elastic)      // 弹性缓动

// 时长
var(--duration-fast)     // 快速 0.15s
var(--duration-normal)   // 正常 0.3s
```

### 动画库
```scss
// 入场动画
@keyframes slideInUp     // 从下到上
@keyframes slideInLeft   // 从左到右
@keyframes slideInDown   // 从上到下
@keyframes fadeIn        // 淡入

// 循环动画
@keyframes breathe       // 呼吸（scale 1-1.1）
@keyframes heartbeat     // 心跳（特殊节奏）
@keyframes pulse         // 脉冲（透明度）
@keyframes pulse-number  // 数字脉冲（scale）
@keyframes float         // 浮动（translateY）

// 状态动画
@keyframes bounce-in     // 弹跳入场
@keyframes shake         // 抖动（错误）
@keyframes bounce        // 上下弹跳

// 模态动画
@keyframes fadeIn        // 遮罩淡入
@keyframes slideInUpModal // 弹窗上滑
```

### 交错动画模式
```scss
// 使用SCSS循环生成交错延迟
@for $i from 1 through 10 {
  &:nth-child(#{$i}) {
    animation-delay: #{$i * 0.1}s;
  }
}
```

## 📝 改造规范总结

### 必须遵循
1. ✅ 使用CSS变量，不使用硬编码颜色
2. ✅ 所有卡片使用统一阴影和圆角
3. ✅ 按钮必须有点击反馈动画
4. ✅ 列表项使用交错入场动画
5. ✅ 重要数字使用脉冲动画
6. ✅ 关键按钮使用心跳动画
7. ✅ 输入框focus必须高亮
8. ✅ 空状态图标使用浮动动画

### 动画时长规范
- **快速**: 0.15s（按钮点击）
- **正常**: 0.3s（Tab切换、卡片入场）
- **慢速**: 0.5-0.6s（列表项交错入场）
- **循环**: 2-3s（呼吸、心跳、脉冲）

### 交错延迟规范
- **密集列表**: 0.1s（任务卡片）
- **稀疏列表**: 0.15s（时间轴节点）
- **最大数量**: 10-20个（避免过长等待）
