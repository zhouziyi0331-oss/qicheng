## 🎨 视觉升级核心

### 1. 色彩系统全面升级

**改造前 - Morandi色系**:
- 背景：浅粉渐变（#F5E6F0）、浅灰（#F9FAFB）
- 卡片：纯白（#FFFFFF）、白色半透明
- 强调色：紫色（#8B5CF6）、粉色（#FF6B9D）
- 装饰色：Morandi绿（#D4F291）、Morandi蓝（#A8D8EA）、Morandi黄（#FFE082）
- 文字：深灰（#2D3436）、中灰（#636E72）、浅灰（#9CA3AF）

**改造后 - 果汁色系**:
- 背景：`var(--theme-bg)` 动态果汁色
- 卡片：`var(--theme-card)` 奶油白
- 主题色：`var(--theme-primary)` → `var(--theme-accent)` 渐变
- 果汁色：
  - 🍓 草莓粉 `var(--strawberry-pink)` #FFF0F3
  - 🫐 蓝莓蓝 `var(--blueberry-blue)` #4ECDC4
  - 🍊 葡萄柚橙 `var(--grapefruit-orange)` #FF6B6B
  - 🥭 芒果黄 `var(--mango-yellow)` #FFE66D
  - 🍉 西瓜红 `var(--watermelon-red)` - 强调色
- 文字：`var(--text-primary/secondary/tertiary)` 动态层级

### 2. 阴影系统统一

**改造前**: 硬阴影，各页面不一致
```scss
box-shadow: 0 8px 32px rgba(0, 0, 0, 0.12);
box-shadow: 0 4px 16px rgba(0, 0, 0, 0.08);
```

**改造后**: 柔和阴影，全局统一
```scss
var(--shadow-card)   // 卡片阴影
var(--shadow-soft)   // 柔和阴影（按钮）
var(--shadow-hover)  // 悬停阴影
var(--shadow-sm)     // 小阴影
```

### 3. 圆角系统规范化

**改造前**: 固定像素值，不统一
```scss
border-radius: 24px;
border-radius: 16px;
border-radius: 48px;
```

**改造后**: 语义化变量
```scss
var(--radius-small)   // 8px
var(--radius-medium)  // 16px
var(--radius-large)   // 24px
var(--radius-round)   // 9999px（胶囊型）
```

## 🎬 动画升级核心

### 1. 入场动画（10个页面全覆盖）

**交错滑入动画** - 最常用模式
```scss
.card {
  opacity: 0;
  transform: translateY(20rpx);
  animation: slideInUp 0.5s var(--ease-decelerate) forwards;
  
  @for $i from 1 through 10 {
    &:nth-child(#{$i}) {
      animation-delay: #{$i * 0.1}s;
    }
  }
}
```

**应用页面**:
- 任务大厅：任务卡片交错滑入
- 故事墙：故事卡片交错滑入
- 首页：功能卡片交错滑入
- 成长报告：指标卡片交错滑入
- 任务邀请：邀请卡片交错滑入

### 2. 绘制动画（数据可视化）

**进度条从0绘制**
```scss
.progress-fill {
  animation: fillBar 1s var(--ease-decelerate);
}

@keyframes fillBar {
  from {
    width: 0;
  }
}
```

**应用场景**:
- 能力雷达：6条能力线从0绘制
- 成长报告：指标进度条从0绘制
- 成长报告：能力条从0绘制
- 首页：等级进度条从0绘制

**图表柱子生长动画**
```scss
.week-bar {
  animation: growBar 1s var(--ease-decelerate);
}

@keyframes growBar {
  from {
    height: 0;
  }
}
```

### 3. 循环动画（持续生命感）

**呼吸动画** - 营造温暖感
```scss
animation: breathe 3s ease-in-out infinite;

@keyframes breathe {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.05); }
}
```

**应用元素**:
- 导师对话：导师头像呼吸
- 首页：用户头像呼吸、Hero Logo呼吸
- TabBar：中央Logo呼吸

**浮动动画** - 装饰元素
```scss
animation: float 3s ease-in-out infinite;

@keyframes float {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-12rpx); }
}
```

**应用元素**:
- 首页：Hero装饰圆浮动
- 故事墙：头部装饰圆浮动
- TabBar：中央按钮浮动
- 空状态：图标浮动

**心跳动画** - 鼓励交互
```scss
animation: heartbeat 2s ease-in-out infinite;

@keyframes heartbeat {
  0%, 100% { transform: scale(1); }
  14%, 28% { transform: scale(1.05); }
  21%, 35% { transform: scale(1); }
}
```

**应用元素**:
- 任务详情：接取按钮心跳
- 任务大厅：挑战按钮心跳
- 故事墙：点赞按钮心跳（激活时）
- 首页：OPC徽章心跳
- 任务邀请：匹配徽章心跳、接受按钮心跳

**脉冲动画** - 吸引注意
```scss
animation: pulse-number 2s ease-in-out infinite;

@keyframes pulse-number {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.05); }
}
```

**应用元素**:
- 钱包：余额数字脉冲
- 任务大厅：价格脉冲
- 任务详情：价格脉冲
- 任务邀请：价格脉冲

### 4. 庆祝动画（关键时刻）

**首单庆祝动画**
- 信封从下弹入（elastic缓动）
- 五彩纸屑四散（8个方向，随机旋转）
- Logo缩放脉冲（3次心跳）

**升级庆祝动画**
- 旧徽章缩小淡出
- 新徽章从小弹入（elastic缓动）
- 粒子爆炸（12个方向，渐变消失）

## 📝 技术实现

### 1. SCSS技术栈

**@for循环实现交错动画**:
```scss
@for $i from 1 through 10 {
  &:nth-child(#{$i}) {
    animation-delay: #{$i * 0.1}s;
  }
}
```

**CSS变量系统**:
```scss
// theme.scss
--theme-bg: #FFF0F3;
--theme-card: rgba(255, 255, 255, 0.95);
--theme-primary: #FF6B9D;
--theme-accent: #FFE66D;
```

**动画关键帧复用**:
```scss
@keyframes slideInUp { ... }
@keyframes breathe { ... }
@keyframes heartbeat { ... }
@keyframes pulse-number { ... }
```

### 2. 缓动函数

**4种核心缓动**:
```scss
--ease-elastic: cubic-bezier(0.68, -0.55, 0.265, 1.55);   // 弹性
--ease-decelerate: cubic-bezier(0, 0, 0.2, 1);            // 减速
--ease-standard: cubic-bezier(0.4, 0, 0.2, 1);            // 标准
--ease-accelerate: cubic-bezier(0.4, 0, 1, 1);            // 加速
```

### 3. 动画时长规范

```scss
--duration-fast: 0.15s;      // 点击反馈
--duration-normal: 0.3s;     // 状态切换
--duration-slow: 0.5s;       // 入场动画
```
