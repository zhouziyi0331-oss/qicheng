# 企业端AI导师功能设计

## 核心定位

AI导师不应该只服务学生端，而应该是**三方协调者**：
- **学生端**：帮助学生理解需求、完成任务、提升能力
- **企业端**：帮助企业发布任务、匹配学生、监控质量
- **平台端**：帮助平台分析数据、优化运营、提升效率

本文档聚焦**企业端AI导师功能**。

---

#### 2. 定价建议
**场景**：企业发布任务时，不知道该给多少钱合适。

**AI导师能做什么**：
- 分析任务描述（复杂度、工作量、技能要求）
- 参考平台历史数据（类似任务的价格分布）
- 给出合理价格区间和建议

**对话示例**：
```
企业：我想让学生帮我做一个简单的落地页，大概多少钱合适？

AI导师：嗯，我看了一下你的需求描述。落地页的话，主要看这几个因素：
1. 页面数量：你说的是单页还是多页？
2. 交互复杂度：有没有表单提交、动画效果？
3. 响应式要求：需要适配移动端吗？

根据平台数据，类似的单页落地页（包含表单+基础动画+响应式），价格一般在 **800-1500元** 之间。

如果你的需求比较简单（纯静态展示），可以给 **500-800元**。
如果需要复杂交互或者多页面，建议 **1500-2500元**。

要不要我帮你把需求再细化一下，这样定价会更准确？
```

**技术实现**：
- 输入：任务描述文本
- 处理：
  1. NLP提取关键特征（技能标签、复杂度关键词）
  2. 查询数据库：相似任务的价格分布
  3. 计算建议价格区间（P25-P75）
- 输出：价格区间 + 解释理由

#### 3. 任务发布辅助
**场景**：企业不知道怎么写任务描述，或者描述不清晰。

**AI导师能做什么**：
- 通过对话引导企业梳理需求
- 生成结构化的任务描述
- 提醒企业补充关键信息（交付标准、验收条件）

**对话示例**：
```
企业：我想做一个小程序，帮我发布任务。

AI导师：好的！我来帮你把需求整理清楚。先问几个问题哈：

1. **小程序的核心功能是什么？**（比如：电商、预约、社交、工具类）
2. **目标用户是谁？**（比如：学生、白领、老年人）
3. **有没有参考案例？**（可以发个链接或者截图）
4. **预算和时间？**（大概多少钱，什么时候要）

你先回答这几个，我帮你生成一个清晰的任务描述，这样学生更容易理解，接单率也会高很多。
```

**生成的任务描述模板**：
```markdown
## 任务标题
开发一个【功能】小程序

## 项目背景
【企业提供的背景信息】

## 核心需求
1. 功能1：【具体描述】
2. 功能2：【具体描述】
3. 功能3：【具体描述】

## 技术要求
- 前端：【技术栈】
- 后端：【技术栈】
- 数据库：【技术栈】

## 交付物
- [ ] 源代码（GitHub仓库）
- [ ] 部署文档
- [ ] 使用说明
- [ ] 测试报告

## 验收标准
1. 【标准1】
2. 【标准2】
3. 【标准3】

## 参考资料
- 【链接或截图】

## 预算和时间
- 预算：【金额】
- 截止日期：【日期】
```

**技术实现**：
- 输入：企业的初始描述
- 处理：
  1. 识别缺失信息（功能、技术栈、交付物、验收标准）
  2. 生成追问问题
  3. 根据回答填充模板
- 输出：结构化任务描述

#### 4. 进度监控提醒
**场景**：企业发布任务后，不知道学生进展如何，容易忘记跟进。

**AI导师能做什么**：
- 主动提醒企业关注任务进展
- 识别风险（延期、卡住、沟通不畅）
- 建议企业采取行动

**提醒示例**：
```
【进度提醒】
你好！你发布的任务《开发落地页》已经进行了3天，目前进度：

✅ 需求确认：已完成
✅ 设计稿：已完成
🟡 前端开发：进行中（预计还需2天）
⚪ 测试：未开始

学生小李的执行情况不错，按计划推进。建议你：
1. 看一下设计稿，确认是否符合预期
2. 如果有调整，尽早提出，避免后期返工

有问题随时找我哦！
```

**风险提醒示例**：
```
【风险提醒】⚠️
你好！你发布的任务《开发小程序》出现了一些风险信号：

🔴 任务已延期2天（原定7天完成，现在第9天）
🔴 学生小王最近2天没有更新进度
🔴 上次沟通时，学生提到"遇到技术难题"

建议你：
1. 主动联系学生，了解具体困难
2. 如果学生确实卡住了，可以考虑：
   - 降低需求复杂度
   - 延长截止日期
   - 或者我帮你联系其他学生协助

要不要我帮你起草一条消息，问问学生的情况？
```

**技术实现**：
- 输入：任务ID、学生行为数据
- 处理：
  1. 计算进度偏差（实际进度 vs 计划进度）
  2. 识别风险信号（延期、无更新、负面情绪）
  3. 生成提醒消息
- 输出：提醒通知（微信消息、站内信）

#### 5. 学生匹配推荐
**场景**：企业发布任务后，不知道选哪个学生。

**AI导师能做什么**：
- 基于任务需求，推荐最合适的学生
- 提供学生的能力画像、历史表现、匹配度分析

**推荐示例**：
```
【学生推荐】
根据你的任务《开发落地页》，我推荐以下3位学生：

🥇 **小李**（匹配度：95%）
- 技能：HTML/CSS/JavaScript ⭐⭐⭐⭐⭐
- 经验：完成过8个类似项目
- 评分：4.8/5.0
- 特点：响应快、代码质量高、擅长响应式设计
- 建议报价：1200元

🥈 **小王**（匹配度：88%）
- 技能：React/Vue ⭐⭐⭐⭐
- 经验：完成过5个类似项目
- 评分：4.6/5.0
- 特点：学习能力强、沟通顺畅
- 建议报价：1000元

🥉 **小张**（匹配度：82%）
- 技能：HTML/CSS ⭐⭐⭐⭐
- 经验：完成过3个类似项目
- 评分：4.5/5.0
- 特点：价格实惠、适合简单需求
- 建议报价：800元

我的建议：如果预算充足，选小李最稳妥。如果想性价比高，小王也不错。
```

**技术实现**：
- 输入：任务描述、学生池
- 处理：
  1. 提取任务技能要求
  2. 计算学生匹配度（技能匹配 + 经验匹配 + 评分）
  3. 排序并生成推荐理由
- 输出：Top 3 学生推荐

#### 6. 质量把关
**场景**：学生提交作品后，企业不知道质量如何，担心验收时发现问题。

**AI导师能做什么**：
- 在学生提交前，AI先进行预审
- 检查常见问题（代码规范、功能完整性、文档齐全）
- 给学生改进建议，减少企业的验收成本

**预审报告示例**：
```
【质量预审报告】
学生小李提交了《开发落地页》的作品，我帮你先审核了一下：

✅ **功能完整性**：所有需求都实现了
✅ **代码质量**：代码规范，注释清晰
✅ **响应式设计**：在手机、平板、电脑上都能正常显示
⚠️ **性能优化**：图片没有压缩，加载速度较慢（建议优化）
⚠️ **浏览器兼容性**：在IE11上有样式问题（如果不需要兼容IE可以忽略）

**我的建议**：
- 整体质量不错，可以验收
- 如果你对性能有要求，建议让学生优化一下图片
- 如果不需要兼容IE，可以直接通过

要不要我帮你生成一个验收清单，方便你逐项检查？
```

**技术实现**：
- 输入：学生提交的代码/文档
- 处理：
  1. 静态代码分析（ESLint、Prettier）
  2. 功能完整性检查（对比需求清单）
  3. 性能检测（Lighthouse）
  4. 生成问题列表和改进建议
- 输出：预审报告

#### 7. 复盘和改进建议
**场景**：任务完成后，企业想知道哪里做得好，哪里可以改进。

**AI导师能做什么**：
- 分析整个任务流程（发布、匹配、执行、验收）
- 给出改进建议，帮助企业下次发布任务更顺利

**复盘报告示例**：
```
【任务复盘报告】
任务《开发落地页》已完成，我帮你复盘一下：

📊 **数据总览**
- 任务周期：7天（按计划完成）
- 沟通轮次：12次
- 修改次数：2次
- 最终评分：4.8/5.0

✅ **做得好的地方**
1. 需求描述清晰，学生理解准确
2. 沟通及时，问题响应快
3. 验收标准明确，减少了返工

⚠️ **可以改进的地方**
1. 设计稿确认晚了1天，导致开发延后
2. 第一次提交时，有2个小问题需要修改（如果提前说明会更好）

💡 **下次建议**
1. 发布任务时，附上设计稿或参考案例，学生更容易理解
2. 在任务描述中明确"不需要兼容IE"，避免学生做无用功
3. 可以设置里程碑（设计稿确认→开发→测试），分阶段验收更高效

总体来说，这次合作很顺利！下次继续保持哦 👍
```

**技术实现**：
- 输入：任务全流程数据（发布、沟通、提交、验收）
- 处理：
  1. 计算关键指标（周期、沟通次数、修改次数）
  2. 识别问题点（延期、返工、沟通不畅）
  3. 生成改进建议
- 输出：复盘报告

#### 8. 需求拆解和里程碑规划
**场景**：企业发布大型任务，不知道怎么拆分。

**AI导师能做什么**：
- 分析任务复杂度
- 拆分为多个阶段
- 规划里程碑和预算
- 降低风险，提高成功率

**拆解示例**：
```
企业：我想做一个完整的电商系统

AI导师：嗯，电商系统比较复杂，我建议拆成几个阶段：
    
阶段1：需求调研（3天，¥500）
- 竞品分析
- 功能清单
- 原型图

阶段2：UI设计（5天，¥1200）
- 首页设计
- 商品详情页
- 购物车和订单页

阶段3：前端开发（10天，¥3000）
- 页面开发
- 接口对接
- 测试

阶段4：后端开发（15天，¥5000）
- 数据库设计
- API开发
- 支付对接

总预算：¥9700
总工期：33天

建议：
- 可以同时招募多个学生，并行开发
- 每个阶段验收后再开始下一阶段
- 降低风险，也方便控制质量
```

**技术实现**：
- 输入：任务描述
- 处理：
  1. NLP分析任务复杂度
  2. 识别关键模块
  3. 估算工作量和时间
  4. 生成里程碑计划
- 输出：分阶段任务计划

#### 9. 竞品任务分析
**场景**：企业想知道同行怎么做，如何定价更合理。

**AI导师能做什么**：
- 分析平台上类似任务
- 对比预算、工期、功能
- 给出定价建议
- 提高任务接单率

**分析示例**：
```
AI导师：我看了一下，最近有3个类似的任务：
    
任务A：【美妆商城小程序】
- 预算：¥1500
- 工期：7天
- 功能：商品展示、购物车、订单
- 结果：5天完成，评分4.8

任务B：【服装商城小程序】
- 预算：¥1200
- 工期：10天
- 功能：商品展示、购物车、订单、会员
- 结果：12天完成（延期2天），评分4.3

任务C：【食品商城小程序】
- 预算：¥2000
- 工期：5天
- 功能：商品展示、购物车、订单、支付
- 结果：无人接单（预算高但工期太短）

建议：
- 你的任务功能类似任务B
- 建议预算：¥1200-1500
- 建议工期：8-10天
- 避免：预算高但工期短，会吓跑学生
```

**技术实现**：
- 输入：任务描述
- 处理：
  1. 提取任务特征（功能、技术栈）
  2. 查询相似任务
  3. 统计价格、工期、成功率
  4. 生成对比分析
- 输出：竞品分析报告

#### 10. 风险预警
**场景**：AI提前发现潜在问题，避免任务失败。

**AI导师能做什么**：
- 分析学生状态（接单数、评分、活跃度）
- 识别任务描述问题
- 评估风险等级
- 给出规避建议

**预警示例**：
```
AI预警：

🔴 高风险：
- 学生【李四】最近接了5个任务，可能精力不足
- 建议：考虑其他学生，或者延长工期

🟡 中风险：
- 你的任务描述中"尽量好看"比较模糊
- 建议：提供参考案例，避免后期返工

🟢 低风险：
- 预算和工期都合理
- 已有3个学生感兴趣
```

**技术实现**：
- 输入：任务信息、学生信息
- 处理：
  1. 评估学生负载（当前接单数）
  2. 分析任务描述清晰度
  3. 对比市场数据（预算、工期）
  4. 计算风险分数
- 输出：风险预警报告

#### 11. 自动催进度
**场景**：学生进度慢，AI自动提醒，语气更温和。

**AI导师能做什么**：
- 监控任务进度
- 自动提醒学生
- 同时通知企业
- 减少企业和学生的直接冲突

**催进度示例**：
```
AI（自动发给学生）：
"嗨张三，你的任务【商城小程序】已经进行了5天，
 按照计划应该完成设计阶段了。
 
 当前进度：设计阶段（预计今天完成）
 
 企业那边比较着急，能今天提交设计稿吗？
 如果有困难，我可以帮你和企业沟通延期。"

AI（同时通知企业）：
"我已经提醒学生加快进度，预计今晚能看到设计稿。"
```

**技术实现**：
- 输入：任务进度数据
- 处理：
  1. 对比计划进度和实际进度
  2. 识别延期风险
  3. 生成温和的提醒消息
  4. 同时通知双方
- 输出：进度提醒消息

### P2 优先级（增值功能）

#### 7. 消息中转和沟通引导 🔥
**场景**：企业和学生沟通时，语气可能生硬，或试图留联系方式。

**AI导师能做什么**：
- 作为中间人，中转所有消息
- 自动屏蔽联系方式（前2次合作）
- 优化语气，减少冲突
- 记录沟通历史，便于纠纷处理

**中转示例1：屏蔽联系方式**：
```
企业输入：
"小伙子做得不错，加我微信细聊：13800138000"

AI审核：
- 检测到联系方式：手机号 13800138000
- 当前合作次数：第1次
- 判断：违规，需要屏蔽

AI处理后发给学生：
"小伙子做得不错，有几个细节我们再聊聊"

AI同时提醒企业：
"您好，我注意到您想留联系方式。
 为了保护双方权益，前2次合作建议通过平台沟通。
 这样可以：
 1. 保留沟通记录，避免纠纷
 2. 平台提供担保，资金安全
 
 等你们合作2次后，如果双方都满意，
 我可以帮你们建立直接联系 :)"
```

**中转示例2：优化语气**：
```
企业输入：
"怎么还没做完？"

AI审核：
- 语气比较生硬
- 可能引起学生反感

AI优化后发给学生：
"嗨，进度怎么样了？企业那边比较着急，
 有什么困难吗？我可以帮忙协调。"

AI同时提醒企业：
"我已经帮您转达了，语气稍微调整了一下，
 这样学生更容易接受 :)
 
 沟通小技巧：
 - 先询问进度，而不是质问
 - 表达理解，提供帮助
 - 学生会更愿意配合"
```

**技术实现**：
- 输入：企业发送的消息、合作次数
- 处理：
  1. 检测联系方式（手机、微信、QQ、邮箱）
  2. 屏蔽违规内容（前2次合作）
  3. 分析语气（调用AI）
  4. 优化表达（如果语气生硬）
  5. 记录原始消息和过滤后消息
- 输出：过滤和优化后的消息

**详细文档**：[消息中转系统设计](mentor-message-relay-system.md)

#### 8. 学生能力评估报告
**场景**：企业想深入了解学生能力（第3次合作后提供详细版）。

**AI导师能做什么**：
- 分析学生历史表现
- 生成能力矩阵
- 提供擅长和不擅长领域
- 帮助企业选择合适的学生

**评估报告示例**：
```
【张三】能力评估报告

技能矩阵：
- 小程序开发：4.2/5.0 ⭐⭐⭐⭐
- UI设计：3.5/5.0 ⭐⭐⭐
- 沟通能力：4.8/5.0 ⭐⭐⭐⭐⭐
- 响应速度：4.5/5.0 ⭐⭐⭐⭐

历史表现：
- 完成任务数：12个
- 平均评分：4.6/5.0
- 按时交付率：90%
- 返工率：15%

擅长领域：
- 电商类小程序（做过5个）
- 简洁风格设计
- 快速迭代

不擅长：
- 复杂动画效果
- 后端开发

企业评价摘录：
- "响应很快，沟通顺畅" - XX公司
- "代码质量不错，但UI还需改进" - YY公司

推荐指数：4/5 ⭐⭐⭐⭐
建议：适合中小型小程序项目，需要提供UI参考
```

**技术实现**：
- 输入：学生ID、历史任务数据
- 处理：
  1. 统计各项能力评分
  2. 分析擅长领域
  3. 提取企业评价
  4. 生成推荐建议
- 输出：能力评估报告

**注意**：
- 前2次合作只提供基础信息（评分、完成数）
- 第3次合作后提供详细评估报告
- 防止企业绕过平台直接联系学生

#### 11. 纠纷调解
**场景**：企业和学生发生分歧（需求理解不一致、质量不满意、延期纠纷）。

**AI导师能做什么**：
- 分析双方沟通记录，找出分歧点
- 提供公正的调解方案
- 帮助双方达成共识

**调解示例**：
```
【纠纷调解】
我看了你和学生小王的沟通记录，目前的分歧是：

**企业方观点**：
- 认为学生延期了3天，应该扣款
- 认为代码质量不达标（有bug）

**学生方观点**：
- 认为延期是因为企业中途改需求
- 认为bug是因为企业没有提供测试数据

**我的分析**：
1. 延期问题：确实有一次需求变更（第3天），但学生也有责任提前沟通延期
2. 质量问题：bug确实存在，但不是致命问题，可以修复

**调解方案**：
1. 学生修复bug（预计1天）
2. 延期扣款：原定1000元，扣除100元（10%），最终900元
3. 双方都做出让步，维护长期合作关系

你觉得这个方案可以接受吗？如果有其他想法，我们可以再商量。
```

**技术实现**：
- 输入：双方沟通记录、任务数据
- 处理：
  1. NLP分析情绪和观点
  2. 识别分歧点
  3. 生成调解方案（基于平台规则）
- 输出：调解建议

企业端AI导师的核心价值：
