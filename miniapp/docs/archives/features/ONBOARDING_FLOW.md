# 新手流程更新说明

## 已完成的功能

### 1. 角色选择页面 (`/pages/role-select/index`)
- 用户登录后首先进入角色选择页
- 两个选项：
  - **需求方**：发布任务，寻找人才
  - **供给方**：接取任务，展示能力
- 选择后跳转到OPC测评

### 2. OPC能力测评页面 (`/pages/opc-test/index`)
- 6道测评题目，覆盖3个维度：
  - **O (开放性)**：探索新方法 vs 稳步推进
  - **P (严谨性)**：详细计划 vs 灵活应对
  - **C (协作性)**：团队协作 vs 独立工作
- 实时进度条显示
- 测评完成后显示：
  - OPC标签（如"探索者·严谨·协作"）
  - 三维能力得分（0-100）
  - 能力条可视化
- 点击"开启OPC之旅"进入首页

### 3. 新手引导组件 (`/components/GuideDialog`)
- 三种引导类型：
  - **首次任务**："开启你的OPC之旅"
  - **首次完成**："恭喜完成首个任务"
  - **等级提升**："恭喜升级到 Lv.X"
- 在任务详情页首次接任务时自动弹出

### 4. 任务详情页面 (`/pages/tasks/detail`)
- 完整的任务信息展示
- 任务描述、要求、标签、发布者
- 底部固定操作栏（报酬+接取按钮）
- 首次接任务时显示引导对话框

## 用户流程

```
微信登录 
  ↓
角色选择（需求方/供给方）
  ↓
OPC能力测评（6道题）
  ↓
查看测评结果（OPC标签+能力得分）
  ↓
进入首页
  ↓
浏览任务大厅
  ↓
点击任务查看详情
  ↓
首次接任务时显示引导："开启你的OPC之旅"
  ↓
接取任务，开始成长之旅
```

## 设计风格

- 延续柔和插画风格
- 淡粉紫背景渐变
- 马卡龙色系强调色
- 超大圆角卡片（28-32rpx）
- Unicode几何图标
- 渐变按钮（嫩草绿→天空蓝）

1. 增加更多测评题目（目前6道，可扩展到12-15道）

3. 添加测评结果分享功能

5. 完善任务完成后的引导流程
