# 设计更新说明 - 纯色圆形图标设计

## 更新概述

已将所有页面的圆形头像/图标更新为**纯色底色 + 黑色线条图标**的设计风格，符合MindMate的扁平插画风格。

## 设计规范

### 核心特征
- **形状**: 正圆形
- **底色**: 纯色填充（绿/粉/蓝/黄），无渐变
- **图标**: 黑色线条风格（outline stroke），无填充
- **线条**: 2px 粗细，圆头端点
- **无阴影**: 扁平设计
- **无emoji**: 全部移除，改用SVG图标或字母

### 配色方案
```scss
$accent-green: #D4F291;  // 嫩草绿
$accent-pink: #F9C6D9;   // 樱花粉
$accent-blue: #A8D8EA;   // 天空蓝
$accent-yellow: #FFE082; // 奶油黄
$accent-orange: #FB923C; // 橙色（AI导师专用）
```

## 设计原则

1. **一致性**: 所有圆形图标使用统一的尺寸比例和线条粗细
2. **识别性**: 图标简洁明了，一眼能看出功能
3. **色彩**: 使用马卡龙色系，柔和温暖
4. **扁平化**: 无阴影、无渐变（底色除外）
5. **可访问性**: 黑色线条确保在任何底色上都清晰可见
