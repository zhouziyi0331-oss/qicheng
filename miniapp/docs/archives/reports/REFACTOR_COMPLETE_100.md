### 动画体系（160个动画）
#### 入场动画（36个页面）
- `slideInUp` - 从下到上滑入（卡片、表单）
- `slideInDown` - 从上到下滑入（头部、标题）
- `slideInLeft` - 从左到右滑入（侧边元素）
- `fadeIn` - 淡入（提示文本）
- `scaleIn` - 缩放入场（标签、徽章）

#### 循环动画
- `breathe` - 呼吸动画（头像、徽章、重要图标）
- `heartbeat` - 心跳动画（提交按钮、行动按钮）
- `pulse` - 脉冲动画（未读标记、加载状态）
- `pulse-number` - 数字脉冲（统计数字、金额）
- `float` - 浮动动画（空状态图标、装饰元素）
- `twinkle` - 闪烁动画（星星、评分）
- `bounce` - 弹跳动画（箭头、引导元素）

#### 状态动画
- `bounce-in` - 弹跳入场（Tab切换、选中状态）
- `shake` - 抖动动画（错误提示、驳回状态）

#### 交错动画
- 卡片列表：0.1s延迟（通用）
- 时间轴节点：0.15s延迟（成长时间轴）
- 表单字段：0.05-0.1s延迟（登录注册）
- 技能标签：0.05s延迟（技能列表）

### 交互优化
- ✅ 所有按钮统一点击反馈：`scale(0.95-0.98)`
- ✅ 所有输入框focus高亮：`border-color + box-shadow`
- ✅ 所有Tab切换动画：`bounce-in + scale`
- ✅ 所有卡片hover效果：`--shadow-hover + translateY`

## 🔧 技术实现亮点

### CSS变量系统
```scss
// 主题色
--theme-primary: #4ECDC4 (蓝莓蓝)
--theme-accent: #7FE5DC (渐变辅助)
--theme-bg: #FFFBF8 (背景)
--theme-card: #FFFFFF (卡片)

// 果汁色
--strawberry-pink: #FFF0F3
--blueberry-blue: #4ECDC4
--grapefruit-orange: #FF6B6B
--mango-yellow: #FFE66D
--watermelon-red: #FF6B9D

// 文本
--text-primary: #2D3436
--text-secondary: #636E72
--text-tertiary: #B2BEC3

// 阴影
--shadow-card: 0 4rpx 16rpx rgba(0,0,0,0.08)
--shadow-soft: 0 2rpx 8rpx rgba(0,0,0,0.06)
--shadow-hover: 0 8rpx 24rpx rgba(0,0,0,0.12)

// 圆角
--radius-small: 8rpx
--radius-medium: 12rpx
--radius-large: 16rpx
--radius-round: 999rpx

// 缓动函数
--ease-standard: cubic-bezier(0.4,0,0.2,1)
--ease-decelerate: cubic-bezier(0,0,0.2,1)
--ease-elastic: cubic-bezier(0.68,-0.55,0.265,1.55)

// 时长
--duration-fast: 0.15s
--duration-normal: 0.3s
```

### SCSS循环生成交错动画
```scss
@for $i from 1 through 10 {
  &:nth-child(#{$i}) {
    animation-delay: #{$i * 0.1}s;
  }
}
```

### 一致的动画模式
所有页面遵循相同的动画模式：
1. 头部/标题：`slideInDown` 0-0.1s
2. 主要内容：`slideInUp/Left` 0.1-0.3s
3. 列表项：交错`slideInUp` 0.1s延迟
4. 底部元素：`fadeIn` 0.5s+
