### 统一设计规范

**色彩变量**:
- `var(--theme-bg)` - 主题背景
- `var(--theme-card)` - 卡片背景
- `var(--text-primary/secondary/tertiary)` - 文字层级

**阴影系统**:
- `var(--shadow-card)` - 卡片阴影
- `var(--shadow-soft)` - 柔和阴影
- `var(--shadow-hover)` - 悬停阴影

**圆角规范**:
- `var(--radius-small)` - 8px
- `var(--radius-medium)` - 16px
- `var(--radius-large)` - 24px
- `var(--radius-round)` - 9999px

**缓动函数**:
- `var(--ease-elastic)` - 弹性缓动
- `var(--ease-decelerate)` - 减速缓动
- `var(--ease-standard)` - 标准缓动

## 🚀 技术亮点

### 1. SCSS高级技巧
```scss
// @for循环实现交错动画
@for $i from 1 through 10 {
  &:nth-child(#{$i}) {
    animation-delay: #{$i * 0.1}s;
  }
}
```

### 2. CSS变量系统
```scss
// 全局主题变量
:root {
  --theme-primary: #FF6B9D;
  --theme-accent: #FFE66D;
  --shadow-card: 0 8rpx 24rpx rgba(0, 0, 0, 0.08);
}
```

### 3. 动画关键帧复用
```scss
@keyframes slideInUp { ... }    // 10个页面复用
```
