# 启程学生端 UI 全局重构计划

## 📋 当前问题

1. **首页问题**：
   - 内容过多（10+个模块）挤在一起
   - 文字排版混乱、重叠
   - 图标比例不对
   - 没有清晰的视觉层次

2. **全局问题**（107个页面）：
   - 删除 CSS 变量导致样式失效
   - 布局混乱、间距不统一
   - 字体大小不一致
   - 卡片样式不统一

## 🎯 设计原则

### 1. 视觉层次（F形阅读模式）
```
顶部：核心信息（Logo、标题、状态）
   ↓
主要内容：1-2个核心功能卡片（大卡片）
   ↓
次要内容：3-4个功能模块（中等卡片）
   ↓
辅助内容：推荐、统计数据（小卡片）
   ↓
底部：TabBar 导航
```

### 2. 果汁色主题保持
- 主色：#EC4899（粉色）
- 背景：#FEF3F8（草莓奶昔粉）
- 卡片：#FFFFFF（白色）
- 强调色：#FF6B6B（西柚橙）、#4ECDC4（蓝莓蓝）

### 3. 统一的设计规范

#### 间距系统（8px 基准）
```scss
$spacing-xs: 8px;    // 极小间距
$spacing-sm: 16px;   // 小间距
$spacing-md: 24px;   // 中等间距
$spacing-lg: 32px;   // 大间距
$spacing-xl: 48px;   // 超大间距
```

#### 字体系统
```scss
$font-xs: 24rpx;     // 小字（说明文字）
$font-sm: 28rpx;     // 正文
$font-md: 32rpx;     // 标题
$font-lg: 36rpx;     // 大标题
$font-xl: 48rpx;     // 超大标题（Slogan）
```

#### 卡片系统
```scss
// 大卡片（核心功能）
.card-primary {
  padding: 32rpx;
  border-radius: 24rpx;
  box-shadow: 0 4rpx 16rpx rgba(0,0,0,0.08);
  min-height: 200rpx;
}

// 中等卡片（功能模块）
.card-secondary {
  padding: 24rpx;
  border-radius: 16rpx;
  box-shadow: 0 2rpx 8rpx rgba(0,0,0,0.06);
  min-height: 160rpx;
}

// 小卡片（统计数据）
.card-tertiary {
  padding: 16rpx;
  border-radius: 12rpx;
  background: rgba(255,255,255,0.6);
  min-height: 120rpx;
}
```

## 📝 实施规范

### 每个页面重构 Checklist：

1. **布局检查**
   - [ ] 使用 ScrollView 包裹内容
   - [ ] 顶部留出安全区域
   - [ ] 底部留出 TabBar 空间
   - [ ] 内容区有适当 padding

2. **间距检查**
   - [ ] 使用统一的间距变量

3. **字体检查**
   - [ ] 使用统一的字体变量
   - [ ] 标题、正文、说明层次清晰
   - [ ] 行高适当（1.5倍）

4. **颜色检查**
   - [ ] 使用主题颜色变量
   - [ ] 背景、卡片、文字颜色统一
   - [ ] 强调色用于重要信息

5. **交互检查**
   - [ ] 点击区域足够大（88rpx+）
   - [ ] 按钮状态明确（normal/hover/disabled）
   - [ ] Loading 状态清晰
