## 📝 关键设计原则

1. **AI导师是核心**：不是附加功能，而是贯穿整个任务流程
2. **陪伴式成长**：学生感受到"被看见"
3. **引导式教育**：不给答案，只给线索
4. **温暖的视觉**：柔和插画风格，年轻化表达
5. **真正的AI驱动**：每个学生都有一对一的精准分析
