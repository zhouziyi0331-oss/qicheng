# 🔧 错误修复指南

## 当前问题分析

你看到的 112 个错误和 26 个警告主要是：

### 错误类型
1. **Error: timeout** - API 调用超时
2. **WAServiceMainContext** - 小程序服务上下文错误

### 原因
这些错误与我们新增的升级验证页面**无关**，是原有页面（特别是首页）在加载时调用了大量API导致的。

### 方案2：修复首页的超时问题

如果你想彻底解决这些错误，需要：

#### 1. 增加API超时时间

编辑 `src/services/api.ts`，找到 `timeout` 配置：

```typescript
// 当前配置
timeout: 60000 // 60秒

// 如果还是超时，可以临时增加到
timeout: 120000 // 120秒
```

#### 2. 添加错误重试机制

在 `src/services/api.ts` 的 `request` 函数中添加重试：

```typescript
async function request(url: string, options: RequestOptions = {}, retryCount = 0) {
  try {
    // 原有代码...
  } catch (error: any) {
    // 如果是超时错误且重试次数少于3次
    if (error.errMsg?.includes('timeout') && retryCount < 3) {
      console.log(`API请求超时，正在重试 (${retryCount + 1}/3)...`)
      return request(url, options, retryCount + 1)
    }
    throw error
  }
}
```

#### 3. 禁用部分非关键API

找到首页 `src/pages/index/index.tsx`，注释掉部分非关键的API调用：

```typescript
// 暂时注释掉一些非关键的加载
// await loadRecommendedTasks()
// await loadAbilityData()
```
