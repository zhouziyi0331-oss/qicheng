## 🔌 后端接口对接

### 接口地址
- 生成验证：`POST /api/level-up-validation/generate`
- 提交答案：`POST /api/level-up-validation/submit`
- 获取历史：`GET /api/level-up-validation/history`

### 数据格式

#### 生成验证 - 请求
```json
{
  "targetLevel": 2
}
```

#### 生成验证 - 响应
```json

  "data": {

    "toLevel": 2,

      { "label": "第3单 · 修改次数", "value": "0 次，直接过", "isGood": true }
```
