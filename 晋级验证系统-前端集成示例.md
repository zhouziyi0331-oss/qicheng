# 晋级验证系统 - 前端集成示例

## 📱 在主页集成晋级通知

### 步骤1：在主页添加状态管理

```tsx
// src/pages/index/index.tsx

import { useState, useEffect } from 'react'
import LevelUpSheet from '../../components/LevelUpSheet'
import { levelUpAPI } from '../../services/levelUpAPI'

export default function Index() {
  // ... 其他状态

  // 晋级验证相关状态
  const [showLevelUpNotification, setShowLevelUpNotification] = useState(false)
  const [showLevelUpSheet, setShowLevelUpSheet] = useState(false)
  const [levelUpCheckData, setLevelUpCheckData] = useState(null)
  const [dialogData, setDialogData] = useState(null)

  useEffect(() => {
    loadUserData()
    checkLevelUpStatus() // 检查是否需要晋级
  }, [])

  // 检查晋级状态
  const checkLevelUpStatus = async () => {
    try {
      const result = await levelUpAPI.checkLevelUp()
      if (result.shouldLevelUp) {
        setLevelUpCheckData(result)
        setShowLevelUpNotification(true)
      }
    } catch (error) {
      console.error('检查晋级失败', error)
    }
  }

  // 点击晋级通知卡
  const handleLevelUpNotificationClick = async () => {
    if (!levelUpCheckData) return

    try {
      Taro.showLoading({ title: '加载中...' })

      // 获取对话内容
      const dialog = await levelUpAPI.getLevelDialog(
        levelUpCheckData.fromLevel,
        levelUpCheckData.toLevel
      )

      setDialogData(dialog)
      setShowLevelUpSheet(true)
      setShowLevelUpNotification(false)

      Taro.hideLoading()
    } catch (error) {
      Taro.hideLoading()
      Taro.showToast({
        title: '加载失败',
        icon: 'none'
      })
    }
  }

  // 提交答案
  const handleAnswer = async (option: string) => {
    if (!levelUpCheckData) return

    try {
      await levelUpAPI.submitAnswer(
        levelUpCheckData.fromLevel,
        levelUpCheckData.toLevel,
        option
      )
    } catch (error) {
      console.error('提交答案失败', error)
    }
  }

  // 确认晋级
  const handleConfirmLevelUp = async () => {
    if (!levelUpCheckData) return

    try {
      Taro.showLoading({ title: '晋级中...' })

      const result = await levelUpAPI.confirmLevelUp(levelUpCheckData.toLevel)

      Taro.hideLoading()
      setShowLevelUpSheet(false)

      // 跳转到晋级完成页
      Taro.navigateTo({
        url: `/pages/level-up-done/index?level=${result.newLevel}&levelTitle=${result.levelTitle}&unlockedPerks=${encodeURIComponent(JSON.stringify(result.unlockedPerks))}`
      })
    } catch (error) {
      Taro.hideLoading()
      Taro.showToast({
        title: '晋级失败',
        icon: 'none'
      })
    }
  }

  // 关闭弹窗
  const handleCloseSheet = () => {
    setShowLevelUpSheet(false)
  }

  return (
    <View className="index-page">
      {/* ... 其他内容 */}

      {/* 晋级通知卡 */}
      {showLevelUpNotification && (
        <View className="level-up-notification" onClick={handleLevelUpNotificationClick}>
          <View className="notification-icon">🎓</View>
          <View className="notification-info">
            <View className="notification-title">导师想跟你说几句话</View>
            <View className="notification-sub">
              {levelUpCheckData.completedCount}单了，有些事想跟你聊聊
            </View>
          </View>
          <View className="notification-arrow">›</View>
        </View>
      )}

      {/* 晋级弹窗 */}
      {dialogData && (
        <LevelUpSheet
          visible={showLevelUpSheet}
          fromLevel={levelUpCheckData.fromLevel}
          toLevel={levelUpCheckData.toLevel}
          mentorText={dialogData.mentorText}
          question={dialogData.question}
          options={dialogData.options}
          mentorReply={dialogData.mentorReply}
          dataCards={dialogData.dataCards}
          timeline={dialogData.timeline}
          onClose={handleCloseSheet}
          onConfirm={handleConfirmLevelUp}
          onAnswer={handleAnswer}
        />
      )}

      {/* TabBar */}
      <TabBar />
    </View>
  )
}
```

## 🔄 完整的使用流程

### 场景1：学生完成任务后

```tsx
// 在任务完成页面
const handleTaskComplete = async (orderId: string) => {
  try {
    // 1. 完成任务
    await taskAPI.complete(orderId)

    // 2. 检查是否需要晋级
    const levelUpCheck = await levelUpAPI.checkLevelUp(orderId)

    if (levelUpCheck.shouldLevelUp) {
      // 3. 触发晋级流程
      Taro.eventCenter.trigger('showLevelUpNotification', levelUpCheck)
    }

    // 4. 返回主页
    Taro.switchTab({ url: '/pages/index/index' })
  } catch (error) {
    console.error('完成任务失败', error)
  }
}
```

### 场景2：从主页触发晋级

```tsx
// 在主页监听晋级事件
useEffect(() => {
  const handleShowLevelUpNotification = (data) => {
    setLevelUpCheckData(data)
    setShowLevelUpNotification(true)
  }

  Taro.eventCenter.on('showLevelUpNotification', handleShowLevelUpNotification)

  return () => {
    Taro.eventCenter.off('showLevelUpNotification', handleShowLevelUpNotification)
  }
}, [])
```

## 🎯 关键交互逻辑

### 1. 弹窗显示时机
- 用户完成足够数量的任务后
- 在主页显示通知卡
- 用户主动点击通知卡

### 2. 选项交互
- 用户点击选项 → 高亮选中
- 300ms后 → 导师回复淡入
- 700ms后 → 关闭按钮和晋级按钮出现
- 用户点击"走，升Lv.X" → 调用确认接口
- 跳转到晋级完成页

### 3. 数据流转
```
checkLevelUp() 
  → shouldLevelUp = true 
  → 显示通知卡
  → 用户点击
  → getLevelDialog()
  → 显示弹窗
  → 用户选择选项
  → submitAnswer()
  → 用户点击晋级
  → confirmLevelUp()
  → 跳转完成页
```

## 📝 注意事项

### 1. Token管理
确保所有API调用都携带有效的token：
```tsx
const token = Taro.getStorageSync('token') || Taro.getStorageSync('access_token')
```

### 2. 错误处理
```tsx
try {
  await levelUpAPI.checkLevelUp()
} catch (error) {
  // 静默失败，不影响主流程
  console.error('检查晋级失败', error)
}
```

### 3. 加载状态
```tsx
Taro.showLoading({ title: '加载中...' })
// ... API调用
Taro.hideLoading()
```

### 4. 路由参数
晋级完成页需要通过URL传递参数：
```tsx
Taro.navigateTo({
  url: `/pages/level-up-done/index?level=${level}&levelTitle=${title}&unlockedPerks=${encodeURIComponent(JSON.stringify(perks))}`
})
```
