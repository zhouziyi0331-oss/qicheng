# 图片资源说明

## Logo 图片
请将猫logo图片放置在此目录：

- **cat-logo.png** - 猫logo主图（建议尺寸：512x512px，PNG格式，透明背景）
- **cat-logo@2x.png** - 2倍图（1024x1024px）
- **cat-logo@3x.png** - 3倍图（1536x1536px）

## 使用方式
```tsx
import catLogo from '../../assets/images/cat-logo.png'

<Image src={catLogo} className="logo" />
```
