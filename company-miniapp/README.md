# 启程企业端小程序

企业端微信小程序，用于企业发布任务、管理任务进度、确认付款等功能。

## 功能模块

### 1. 首页（index）
- 数据概览：总任务数、进行中、已完成、总支出
- 快速操作：发布任务、查看任务、付款管理
- 最近任务列表

### 2. 任务管理（tasks）
- 任务列表：全部、进行中、待处理、已完成
- 任务详情：标题、描述、执行学生、预算、截止日期、进度
- 任务操作：确认完成、查看进度、查看匹配学生

### 3. 发布任务（publish）
- 任务信息：标题、描述、类别、预算、截止日期
- 技能要求：列出对学生的技能要求
- AI智能匹配：自动匹配5位合适的学生

### 4. 付款管理（payments）
- 付款列表：待处理、已完成
- 付款操作：立即付款、查看交付物
- 统计信息：总支出、待付款

### 5. 企业中心（profile）
- 企业信息：名称、联系人、电话、邮箱、行业、规模
- 统计数据：发布任务、进行中、已完成
- 功能菜单：我的任务、付款记录、收藏的学生、数据统计、账号设置、帮助中心

## 技术栈

- Taro 3.6.39
- React 18
- TypeScript
- 微信小程序

## 开发运行

```bash

# 开发模式
npm run dev

# 构建
npm run build
```

## 与后端对接

企业端小程序需要对接以下API：

- `POST /api/tasks` - 发布任务
- `GET /api/tasks/company` - 获取企业任务列表
- `GET /api/tasks/:id` - 获取任务详情
- `PUT /api/tasks/:id/confirm` - 确认任务完成
- `GET /api/payments/company` - 获取付款列表
- `POST /api/payments/:id/pay` - 执行付款
- `GET /api/company/profile` - 获取企业信息

## 业务流程

1. 企业发布任务
2. AI智能匹配5位合适的学生
3. 推送任务邀请给学生
4. 学生接受/拒绝邀请
5. 企业从接受的学生中选择1位
6. 学生执行任务
7. 企业查看任务进度
8. 学生提交交付物
9. 企业确认完成并付款
