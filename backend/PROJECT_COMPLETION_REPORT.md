## 🎯 核心能力

### 1. 情绪感知 ✅

**能力**：
- 实时检测7种情绪（焦虑、沮丧、困惑、兴奋、自信、不堪重负、自豪）
- 量化情绪强度（0-1）
- 识别情绪信号词汇
- 追踪情绪历史

**实现**：
- `EmotionAnalysisService` - 规则检测 + AI增强
- `student_emotion_log` 表 - 完整的情绪记录
- `emotion_response_strategies` 表 - 7种情绪的响应策略

**成本**：~$0.0001/次

### 2. 成长追踪 ✅

**能力**：
- 自动检测9种里程碑
- 记录前后状态对比
- 量化成长指标
- 自动生成庆祝消息

**实现**：
- `GrowthTrackingService` - 规则 + AI检测
- `student_growth_milestones` 表 - 里程碑记录
- `student_learning_profiles` 表 - 完整的学生档案

**成本**：~$0.0001/次

### 3. 记忆系统 ✅

**能力**：
- 记住困难、突破、模式、偏好
- 自动提取记忆
- 智能召回相关记忆
- 记忆关联和重要性评分

**实现**：
- `MentorMemoryService` - 完整的记忆管理
- `mentor_memory` 表 - 长期记忆存储
- 自动提取（每5条消息）

**成本**：~$0.0002/次（每5条消息）

### 4. 自适应引导 ✅

**能力**：
- 根据情绪调整语气和方法
- 根据学习风格调整方式
- 根据历史调整策略
- 个性化系统提示

**实现**：
- `AdaptiveGuidanceService` - 整合所有数据
- 智能模型选择（Haiku vs Sonnet）
- 动态调整引导策略

**成本**：~$0.003/次

### 5. 人性化对话 ✅

**能力**：
- 像朋友一样说话
- 用"我"不用"系统"
- 先共情再解决
- 记得过去，提起细节

**实现**：
- `HumanizedConversationService` - 人性化回复生成
- `mentor_conversation_phrases` 表 - 对话片段库
- `mentor_humanized_context` 表 - 关系和承诺

**成本**：~$0.006/次

### 6. 工具推荐 ✅

**能力**：
- 分析任务类型
- 推荐合适工具
- 说明为什么推荐
- 给出具体步骤
- 跟踪使用效果

**实现**：
- `ToolRecommendationService` - 智能推荐
- `mentor_tool_recommendations` 表 - 工具库（5个预置）
- `mentor_tool_usage_tracking` 表 - 使用跟踪

**预置工具**：
1. 即时设计 - UI设计
2. Cursor - AI编程助手
3. 微信开发者工具 - 小程序开发
4. ChatGPT - AI对话助手
5. Notion - 项目管理

### 7. 主动跟进 ✅

**能力**：
- 检测不活跃学生（24小时没回复）
- 检测遇到困难的学生
- 检测需要工具反馈的学生
- 检测未庆祝的里程碑
- 自动生成跟进消息

**实现**：
- `ProactiveFollowUpService` - 主动跟进逻辑
- `MentorScheduler` - 定时任务调度
- 每小时自动执行

**跟进类型**：
- inactive - 不活跃跟进
- struggling - 困难跟进
- tool_feedback - 工具反馈跟进
- celebrate - 庆祝跟进

### 8. 深度引导 ✅

**能力**：
- 识别8种深层模式（恐惧、完美主义、需要认可、比较心态、失败恐惧、控制欲、僵化沟通、孤立）
- 看到问题背后的信念
- 挑战限制性信念
- 提供新视角
- 引导行为改变（5阶段：识别→承认→挑战→重构→实践）

**实现**：
- `DeepGuidanceService` - 深层模式识别和引导
- `mentor_deep_patterns` 表 - 8种预设模式
- `student_deep_patterns` 表 - 学生模式记录
- `mentor_deep_dialogue_templates` 表 - 对话模板
- `student_belief_shifts` 表 - 信念转变追踪
- `student_growth_challenges` 表 - 成长挑战

**8种深层模式**：
1. **对未知的恐惧** - "不会" ≠ "学不会"
2. **完美主义/拖延** - "开始"比"完美"更重要
3. **需要外部认可** - 建立内在价值感
4. **比较心态** - 每个人的节奏不同
5. **对失败的恐惧** - 失败是学习的一部分
6. **需要控制** - 接受不确定性
7. **僵化沟通** - 学会表达需求
8. **孤立/不敢求助** - 求助是力量的表现

**成本**：~$0.008/次

### 9. 定时任务 ✅

**任务**：
1. 主动跟进 - 每小时
2. 记忆清理 - 每天凌晨3点
3. 学习模式分析 - 每6小时

**实现**：
- `MentorScheduler` - 基于node-cron
- 自动启动和停止
- 手动触发支持

```
嗯嗯，UI设计是吧。我看了一下你的任务，

好，我明白了。其实你这个情况很常见，
很多人第一次做设计都是这样的。

我帮你分析一下：

你这个任务需要：
1. 画出界面原型（就是线框图，黑白的那种）
2. 设计视觉稿（加上颜色、图标）
3. 标注尺寸（给开发看的）

听起来很多对吧？但其实有个好消息——
你不需要从零开始学设计。

我推荐你用 **即时设计**（免费的）：

🎨 为什么推荐它：
- 中文界面，上手快
- 有现成的电商小程序模板
- 你可以直接套模板改，30分钟就能出一版

具体怎么做：
1. 去 js.design 注册一个账号
2. 搜索"电商小程序"或"商城小程序"
3. 找一个你觉得好看的模板，复制一份
4. 改成你任务需要的样子（改文字、换图片）

你不需要从零画，改模板就行。
就像你不会做饭，但可以照着菜谱做，对吧？

要不你先去注册一个账号，试着找找模板？
找到了跟我说一声，我教你怎么改。

（别担心，我一直在这儿陪着你）
```

**优势**：
- ✅ 先共情，再分析
- ✅ 分解任务，降低焦虑
- ✅ 推荐具体工具，说明原因
- ✅ 给出详细步骤
