  tsm.task_id,

  tsm.overall_score,
  tsm.skill_match_score,
  tsm.difficulty_match_score,
  tsm.is_pushed,
  tsm.student_viewed,
  tsm.student_accepted

- [ ] 6个维度分数都存在
- [ ] 推送的学生is_pushed=true

#### 4.2 检查AI导师会话
**SQL查询**:
```sql
SELECT 
  ms.id,
  ms.student_id,
  ms.task_id,
  ms.stage,
  ms.emotion_state,
  COUNT(mm.id) as message_count
FROM mentor_sessions ms
LEFT JOIN mentor_messages mm ON mm.session_id = ms.id
GROUP BY ms.id
ORDER BY ms.created_at DESC
LIMIT 10;
```

**验证点**:
- [ ] 有导师会话记录
- [ ] 会话关联正确的学生和任务
- [ ] 有消息记录
- [ ] 情绪状态被记录

#### 4.3 检查工具提示使用
**SQL查询**:
```sql
SELECT 
  tool_name,
  COUNT(*) as usage_count
FROM mentor_messages
WHERE tool_name IS NOT NULL
GROUP BY tool_name
ORDER BY usage_count DESC;
```
