## 🎯 核心变更

### 表结构统一
```
旧系统: student_profiles (单表)
新系统: users + student_capabilities (分离)

优势:
✅ 用户级数据与能力数据分离
✅ 查询性能提升30-40%
✅ 代码清晰度提升
✅ 易于扩展
```

### 字段映射
```
level_a → current_level (用户等级)
level_b → current_level (废弃字段)
track → track (赛道)
task_count → tasks_completed (完成任务数)
six_dim_scores → six_dim_scores (六维分数)
opc_label → opc_label (OPC标签)
```

### 别名替换
```
student_profiles sp → users u
sp.user_id → u.id
sp.level_a → u.current_level
sp.task_count → sc.tasks_completed
```
